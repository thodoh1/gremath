# Lesson M-627 — Supremum

Part O. O. Real Analysis · **Real-number foundations** · High

Prerequisites: `A.1`.


This lesson isolates **Supremum** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Real analysis items are often ‘which statement is true?’ definition checks inside additional topics.

## 1. Why this skill exists

If you cannot do **Supremum**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Real-number foundations*

$\mathbb{R}$ is a complete ordered field: every nonempty set bounded above has a least upper bound. Suprema, infima, Archimedean property, density of $\mathbb{Q}$ and of irrationals, nested intervals.

### This skill, specifically

$\mathbb{R}$ is a complete ordered field: every nonempty set bounded above has a least upper bound.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

An upper bound of $S$ is any $M$ with $s\le M$ for all $s\in S$. The supremum $\sup S$ is the least upper bound. Equivalently: $M=\sup S$ iff $M$ is an upper bound and for every $\varepsilon>0$ there is $s\in S$ with $s>M-\varepsilon$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Find $\sup(0,1)$ and $\sup\{1-1/n:n\in\mathbb{N}\}$.

**Solution.** Both equal $1$. Neither set contains $1$, so neither has a maximum.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $\sup\{n/(n+1):n\in\mathbb{N}\}$ equals

**Solution.** $1$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Writing $\sup S=\infty$ as if $\infty$ were a real number without saying extended reals.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** If $S=\{2,5,5,7\}$, $\sup S$.

**Solution.** $7$ (and $\max S=7$).

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Is $\sup[-1,0)=\sup(-1,0)$?

**Solution.** Yes, both $0$.

## 9. Lock it in
