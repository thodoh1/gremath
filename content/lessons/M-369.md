# Lesson M-369 — Parametrized curves

Part I. I. Vector Calculus · **Line integrals** · High

Prerequisites: `I.1`.


This lesson isolates **Parametrized curves** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Vector calculus (Green/Stokes/divergence) appears less often than single-variable calculus but is a high-leverage discriminator.

## 1. Why this skill exists

If you cannot do **Parametrized curves**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Line integrals*

Scalar line integrals weight by arc length. Vector line integrals measure work $\int_C\mathbf{F}\cdot d\mathbf{r}$. Conservative fields are gradients: path independence, $\mathbf{F}=\nabla f$, curl zero (on simply connected domains).

### This skill, specifically

Scalar line integrals weight by arc length.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

To integrate along a curve you must parametrize it: choose $\mathbf{r}(t)$ with the correct endpoints, orientation, and image. Circles: $\mathbf{r}(t)=\mathbf{c}+R(\cos t,\sin t)$; line segments: $\mathbf{r}(t)=\mathbf{a}+t(\mathbf{b}-\mathbf{a})$, $t\in[0,1]$. Speed $|\mathbf{r}'|$ is not unique.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Parametrize the circle $(x-1)^2+(y+2)^2=9$, counterclockwise once.

**Solution.** $\mathbf{r}(t)=(1+3\cos t,-2+3\sin t)$, $t\in[0,2\pi]$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** A parametrization of the segment from $(2,3)$ to $(5,3)$ is

**Solution.** $\mathbf{r}(t)=(2+3t,3)$, $t\in[0,1]$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Using $x=\cos t$, $y=\sin t$ for a circle not centered at the origin, or traversing clockwise when the problem said positive orientation.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Parametrize $y=x^2$ from $(0,0)$ to $(2,4)$.

**Solution.** $\mathbf{r}(t)=(t,t^2)$, $t:0\to 2$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Does $\mathbf{r}(t)=(t^2,t^4)$, $t:0\to\sqrt{2}$, trace the same parabola segment?

**Solution.** Yes as a set, but not at the same speed.

## 9. Lock it in

You own this skill when you can do Drill 1 and Drill 2 tomorrow, mixed among unrelated problems, in under five minutes each, with the traps named in Section 7 avoided on purpose.
