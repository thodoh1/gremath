# Lesson M-972 — Stability

Part X. X. Numerical Analysis · **Numerical error** · Medium

Prerequisites: `A.1`.


This lesson isolates **Stability** and trains it until it is automatic.

This is a Medium skill: it appears less often, but when it appears it is often a discriminator. Numerical methods are additional topics: Newton, error, quadrature recognition.

## 1. Why this skill exists

If you cannot do **Stability**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Numerical error*

Absolute vs relative error, roundoff vs truncation, floating point, conditioning of a problem vs stability of an algorithm.

### This skill, specifically

Absolute vs relative error, roundoff vs truncation, floating point, conditioning of a problem vs stability of an algorithm.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

An algorithm is stable if it produces an answer close to the exact solution of a nearby problem (backward stability) or keeps forward error comparable to $\kappa$ times machine noise. Unstable algorithms can destroy even well-conditioned problems (e.g. forming $x^2-y^2$ instead of $(x-y)(x+y)$ when $x\approx y$). Stability is about the method; condition is about the map.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Which is more stable for $x\approx y$: $x^2-y^2$ or $(x-y)(x+y)$?

**Solution.** $(x-y)(x+y)$: the cancellation is explicit in $x-y$, often exact if $x,y$ are nearby floats, whereas $x^2-y^2$ cancels after rounding squares.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Gaussian elimination without pivoting on $\begin{pmatrix}10^{-20}&1\\ 1&1\end{pmatrix}$ is a classic

**Solution.** unstable algorithm for a well-enough-conditioned $2\times 2$ system.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Saying a high condition number means the algorithm is unstable, without distinguishing problem vs method.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Backward error of an approximate root $\hat r$ of $f$ is

**Solution.** the perturbation of $f$ (or of the coefficients) that makes $\hat r$ exact.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Forward error is

**Solution.** $|\hat r-r_{\mathrm{true}}|$ (or a relative version).
