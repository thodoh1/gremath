# Lesson M-888 — Confidence intervals

Part U. U. Mathematical Statistics · **Inference** · Medium

Prerequisites: `U.1-U.2`.


This lesson isolates **Confidence intervals** and trains it until it is automatic.

This is a Medium skill: it appears less often, but when it appears it is often a discriminator. Statistics is lighter than probability but bias, MLE, and tests do appear.

## 1. Why this skill exists

If you cannot do **Confidence intervals**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

A confidence interval of level $1-\alpha$ is a random set $C(\mathbf{X})$ with $P_\theta(\theta\in C(\mathbf{X}))=1-\alpha$ (or at least $1-\alpha$) for all $\theta$. After data are seen, the realized interval either contains $\theta$ or not — the probability statement is about the procedure. Normal mean, $\sigma$ known: $\bar X\pm z_{\alpha/2}\sigma/\sqrt{n}$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** $n=16$, $\bar x=10$, $\sigma=4$, $z_{0.025}=1.96$. Approximate $95\%$ CI for $\mu$.

**Solution.** $10\pm 1.96\cdot 4/4=10\pm 1.96$, i.e. $(8.04,11.96)$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Does a realized $95\%$ CI ‘contain $\mu$ with probability $0.95$’?

**Solution.** No: $\mu$ is fixed; the coverage claim is frequentist, before seeing data.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Interpreting $95\%$ as $P(\mu\in(8,12)\mid\text{these data})=0.95$ without a prior, or using $z$ with unknown $\sigma$ and $n=8$.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Width of $\bar X\pm z_{\alpha/2}\sigma/\sqrt{n}$ as a function of $n$.

**Solution.** Shrinks like $1/\sqrt{n}$.

Cover that solution, redo the drill on paper, then continue.
