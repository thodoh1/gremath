# Lesson M-428 — Matrix notation

Part K. K. Linear Algebra · **Matrices** · Critical

Prerequisites: `K.1`.


This lesson isolates **Matrix notation** and trains it until it is automatic.

This is a Critical skill: it is used constantly, and a hole here leaks points all over the paper. Linear algebra is a large share of the algebra portion. Rank, kernels, eigenvalues, and determinants are exam staples.

## 1. Why this skill exists

If you cannot do **Matrix notation**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Matrices*

Matrices encode linear maps and systems. Multiplication is composition, not entrywise. Transpose, inverse, special shapes (diagonal, triangular, symmetric) are computational gold.

### This skill, specifically

Matrices encode linear maps and systems.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

An $m\times n$ matrix $A=(a_{ij})$ has $m$ rows and $n$ columns; $a_{ij}$ sits in row $i$, column $j$. Two matrices are equal iff they have the same size and entries. A column vector is $n\times 1$; a row vector is $1\times n$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** $A=\begin{pmatrix}1&2&3\\4&5&6\end{pmatrix}$. Size, and $a_{23}$.

**Solution.** $2\times 3$, $a_{23}=6$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $a_{12}$ of $\begin{pmatrix}7&8\\9&0\end{pmatrix}$ is

**Solution.** $8$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Reading $a_{ij}$ as column $i$, row $j$ (swapping the index convention).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** How many entries in a $3\times 5$ matrix?

**Solution.** $15$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Is a $1\times 4$ matrix a vector in $\mathbb{R}^4$ as a column?

**Solution.** No: it is a row; the column version is $4\times 1$.
