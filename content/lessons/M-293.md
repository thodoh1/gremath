# Lesson M-293 — Bounded monotone convergence theorem

Part G. G. Infinite Series · **Sequences** · Critical

Prerequisites: `E.1; O.1`.


This lesson isolates **Bounded monotone convergence theorem** and trains it until it is automatic.

This is a Critical skill: it is used constantly, and a hole here leaks points all over the paper. Series tests and Taylor series are standard GRE calculus. Do not treat this part as optional analysis.

## 1. Why this skill exists

If you cannot do **Bounded monotone convergence theorem**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

Bounded monotone convergence theorem: a monotone bounded real sequence converges. This uses completeness of $\mathbb{R}$ (the limit is the sup of the set of terms for an increasing sequence). False in $\mathbb{Q}$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Why $a_n=$ increasing enumeration of rationals in $(0,\sqrt{2})$ need not converge in $\mathbb{Q}$.

**Solution.** It is increasing and bounded in $\mathbb{Q}$ but the sup $\sqrt{2}\notin\mathbb{Q}$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** A bounded sequence that is not monotone

**Solution.** Need not converge: $(-1)^n$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Using BMCT in $\mathbb{Q}$ as if $\mathbb{Q}$ were complete.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Increasing and $a_n\le 5$: conclusion?

**Solution.** Converges to some $L\le 5$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Name the axiom that makes BMCT true in $\mathbb{R}$.

**Solution.** Completeness / LUB property.
