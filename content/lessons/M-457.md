# Lesson M-457 — Rank-nullity theorem

Part K. K. Linear Algebra · **Vector spaces** · Critical

This lesson isolates **Rank-nullity theorem** and trains it until it is automatic.

This is a Critical skill: it is used constantly, and a hole here leaks points all over the paper. Linear algebra is a large share of the algebra portion. Rank, kernels, eigenvalues, and determinants are exam staples.

## 1. Why this skill exists

If you cannot do **Rank-nullity theorem**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

Rank-nullity theorem: if $A$ is $m\times n$, then $\mathrm{rank}\,A+\mathrm{nullity}\,A=n$. Equivalently $\dim\mathrm{Col}\,A+\dim\mathrm{Nul}\,A=n$. For a linear map $T:V\to W$ with $\dim V$ finite, $\dim\ker T+\dim\mathrm{im}\,T=\dim V$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

## 5. Worked example

**Problem.** A $3\times 5$ matrix has rank $2$. Find $\dim\mathrm{Nul}\,A$.

**Solution.** $5-2=3$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** If $T:\mathbb{R}^4\to\mathbb{R}^3$ has $\dim\mathrm{im}\,T=3$, then $\dim\ker T$ is

**Solution.** $1$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Using $m$ instead of $n$ on the right-hand side (mixing rows with columns).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Can a $4\times 4$ matrix have rank $3$ and nullity $2$?

**Solution.** No: $3+2\neq 4$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Full column rank means nullity

**Solution.** $0$, hence injective $A\mathbf{x}\mapsto$ map.
