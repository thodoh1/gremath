# Lesson M-754 — Distinguishing syntax from semantics

Part Q. Q. Logic, Sets & Proof · **Foundational awareness** · Medium

Prerequisites: `Q.1-Q.5`.


This lesson isolates **Distinguishing syntax from semantics** and trains it until it is automatic.

This is a Medium skill: it appears less often, but when it appears it is often a discriminator. Logic and proof are how other items are worded. Counting and analysis both depend on quantifiers.

## 1. Why this skill exists

If you cannot do **Distinguishing syntax from semantics**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Foundational awareness*

Russell’s paradox motivates distinguishing sets from “too large” collections. Syntax vs semantics: a string vs its meaning. Axioms are starting rules, not optional poetry.

### This skill, specifically

Russell’s paradox motivates distinguishing sets from “too large” collections.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

Syntax is the formal language: symbols, well-formed formulas, rules of inference, proofs ($\vdash$). Semantics is meaning in a structure: satisfaction, truth ($\models$). Soundness: provable implies true in all models. G\"odel completeness (first-order): conversely, if $\Gamma\models\phi$ then $\Gamma\vdash\phi$. A sentence can be true in one model and false in another.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Distinguish ``$G$ is a group'' as a syntactic axiom set vs a semantic statement about a particular $(G,\cdot)$.

**Solution.** The group axioms are strings one may derive theorems from. A particular set with an operation either satisfies those axioms (is a model) or not.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Soundness says that if $\vdash\phi$ then

**Solution.** every model satisfies $\phi$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Confusing ``true'' with ``provable'' in a system that may be incomplete (G\"odel incompleteness for arithmetic).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Is ``$\mathbb{R}$ is complete'' a first-order property of the ordered field of reals?

**Solution.** No: completeness is a second-order / supremum statement about all subsets; many non-complete models satisfy the first-order theory of real closed fields.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Completeness theorem vs incompleteness theorem.

**Solution.** Completeness: first-order semantic entailment = syntactic derivability. Incompleteness: Peano arithmetic does not decide every arithmetic sentence.
