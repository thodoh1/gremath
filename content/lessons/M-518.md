# Lesson M-518 — Euler phi function

Part L. L. Number Theory · **Euler/Fermat tools** · High

Prerequisites: `L.2`.


This lesson isolates **Euler phi function** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Number theory is additional-topics / algebra: congruences, Euler, CRT.

## 1. Why this skill exists

If you cannot do **Euler phi function**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Euler/Fermat tools*

Fermat: $a^{p-1}\equiv 1\pmod p$ if $p\nmid a$. Euler: $a^{\phi(n)}\equiv 1\pmod n$ if $\gcd(a,n)=1$. $\phi$ is multiplicative. Orders divide $\phi(n)$.

### This skill, specifically

Fermat: $a^{p-1}\equiv 1\pmod p$ if $p\nmid a$.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

Euler's totient $\phi(n)$ counts integers in $\{1,\ldots,n-1\}$ coprime to $n$ (and $\phi(1)=1$). Equivalently $\phi(n)=|(\mathbb{Z}/n\mathbb{Z})^\times|$. $\phi(p)=p-1$, $\phi(p^k)=p^k-p^{k-1}=p^{k-1}(p-1)$, and $\phi$ is multiplicative on coprime arguments.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** List the units counted by $\phi(12)$ and compute $\phi(12)$.

**Solution.** $\{1,5,7,11\}$, so $\phi(12)=4$. Formula: $12=2^2\cdot 3$, $\phi=12(1-1/2)(1-1/3)=4$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $\phi(p)$ for prime $p$ is

**Solution.** $p-1$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Counting $0$ among the totatives, or using $\phi(p^k)=p^k-1$.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** $\phi(10)$.

**Solution.** $4$: residues $1,3,7,9$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** $\phi(1)+\phi(2)+\phi(5)+\phi(10)$ equals

**Solution.** $1+1+4+4=10$, illustrating $\sum_{d\mid n}\phi(d)=n$ for $n=10$.
