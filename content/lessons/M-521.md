# Lesson M-521 — Units modulo n

Part L. L. Number Theory · **Euler/Fermat tools** · High

Prerequisites: `L.2`.


This lesson isolates **Units modulo n** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Number theory is additional-topics / algebra: congruences, Euler, CRT.

## 1. Why this skill exists

If you cannot do **Units modulo n**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Euler/Fermat tools*

Fermat: $a^{p-1}\equiv 1\pmod p$ if $p\nmid a$. Euler: $a^{\phi(n)}\equiv 1\pmod n$ if $\gcd(a,n)=1$. $\phi$ is multiplicative. Orders divide $\phi(n)$.

### This skill, specifically

Fermat: $a^{p-1}\equiv 1\pmod p$ if $p\nmid a$.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

The group of units modulo $n$ is $(\mathbb{Z}/n\mathbb{Z})^\times=\{[a]:\gcd(a,n)=1\}$ under multiplication mod $n$. It has order $\phi(n)$. $[a][b]=[1]$ iff $b\equiv a^{-1}$. Wilson: $(p-1)!\equiv -1\pmod{p}$ for $p$ prime, because the units pair as inverses except $\pm 1$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** List $(\mathbb{Z}/8\mathbb{Z})^\times$ and its multiplication table's identity.

**Solution.** $\{1,3,5,7\}$. Each squares to $1\bmod 8$: Klein four-group, not cyclic.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $(\mathbb{Z}/7\mathbb{Z})^\times$ has order

**Solution.** $6$, cyclic generated by $3$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Including residue $0$ when $n>1$, or thinking every nonzero class is a unit when $n$ is composite.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Units mod $15$.

**Solution.** $1,2,4,7,8,11,13,14$ ($\phi(15)=8$).

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Inverse of $7$ in $(\mathbb{Z}/15\mathbb{Z})^\times$.

**Solution.** $13$, because $91=6\cdot 15+1$.
