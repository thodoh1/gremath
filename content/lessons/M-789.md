# Lesson M-789 — Paths

Part S. S. Graph Theory & Algorithms · **Graph basics** · Medium

Prerequisites: `Q.4-R.1`.


This lesson isolates **Paths** and trains it until it is automatic.

This is a Medium skill: it appears less often, but when it appears it is often a discriminator. Graph theory is additional topics: trees, Euler, handshaking, planarity.

## 1. Why this skill exists

If you cannot do **Paths**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

A path is a walk with no repeated vertex (hence no repeated edge). The path graph $P_n$ has $n$ vertices and $n-1$ edges. Distance $d(u,v)$ is the least length of a $u$--$v$ path (undefined or $\infty$ if none). A graph is a path iff $\delta=\Delta=2$ except two ends of degree $1$, and it is connected.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** How many distinct $u$--$v$ paths in $K_4$ between two fixed vertices, of vertex-length $2$ (one interior vertex)?

**Solution.** $2$ choices for the interior vertex among the other two vertices? $K_4$ has two other vertices; each gives a path of length $2$. (Length $1$ is the direct edge.)

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Is $v_1 v_2 v_1$ a path?

**Solution.** No: vertex $v_1$ repeats. It is a closed walk of length $2$ (an out-and-back).

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Using walk, trail, and path as synonyms. GRE questions often hinge on the distinction.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Number of vertices in a path with $11$ edges.

**Solution.** $12$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** In a tree on $9$ vertices, number of paths between a given pair $u\neq v$.

**Solution.** Exactly one.
