# Lesson M-918 — Secant properties

Part V. V. Geometry · **Circle & polygon geometry** · High

This lesson isolates **Secant properties** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Geometry is additional topics plus analytic geometry inside calculus/algebra items.

## 1. Why this skill exists

If you cannot do **Secant properties**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

A secant intersects a circle in two points. Power from an external point $P$: if secant $PAB$ (through $A$ then $B$) and secant $PCD$, then $PA\cdot PB=PC\cdot PD$. If instead $PT$ is tangent, $PA\cdot PB=PT^2$. Intersecting-chords is the internal version of the same power.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Tangent $PT=6$, secant $PAB$ with $PA=4$. Find $AB$.

**Solution.** $PA\cdot PB=36$, $4\cdot PB=36$, $PB=9$, so $AB=5$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Solution.** $PA\cdot PB/PC=24/4=6$, hence $CD=2$.

## 7. Traps that cost points

- Writing $PA\cdot AB=PT^2$ (wrong segments: whole secant segment $PB$, not the internal chord alone).
- Skip checking a candidate in the original equation.
