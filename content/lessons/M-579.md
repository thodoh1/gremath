# Lesson M-579 — Conjugacy classes

Part M. M. Group Theory · **Group actions** · Medium

Prerequisites: `M.4`.


This lesson isolates **Conjugacy classes** and trains it until it is automatic.

This is a Medium skill: it appears less often, but when it appears it is often a discriminator. Group theory is the main abstract-algebra GRE diet: orders, Lagrange, homomorphisms.

## 1. Why this skill exists

If you cannot do **Conjugacy classes**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Group actions*

An action is a homomorphism $G\to S_X$. Orbit-stabilizer: $|G|=|\mathrm{Orb}|\,|\mathrm{Stab}|$. Conjugacy is a special action. Finite abelian groups decompose into cyclic groups.

### This skill, specifically

An action is a homomorphism $G\to S_X$.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

Conjugacy classes partition $G$. The class equation: $|G|=|Z(G)|+\sum |cl(a_i)|$ over representatives of non-central classes, and each class size $|cl(a)|=[G:C_G(a)]$ divides $|G|$. $p$-groups have nontrivial center. Class sizes in $S_n$ are $n!$ divided by the centralizer order computed from cycle type.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Class equation of $S_3$.

**Solution.** Classes: $\{e\}$, the three transpositions, the two $3$-cycles. $6=1+3+2$. Center trivial.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Class size of a $3$-cycle in $S_4$

**Solution.** Number of $3$-cycles: $\binom{4}{3}\cdot 2=8$. (The leftover letter is fixed.)

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Adding class sizes that do not divide $|G|$.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Does a class of size $2$ exist in a group of order $15$?

**Solution.** $2\nmid 15$, no.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Center of a $p$-group.

**Solution.** Nontrivial (class equation: $p\mid|G|$ and $p$ divides noncentral class sizes, so $p\mid|Z|$).

## 9. Lock it in

You own this skill when you can do Drill 1 and Drill 2 tomorrow, mixed among unrelated problems, in under five minutes each, with the traps named in Section 7 avoided on purpose.
