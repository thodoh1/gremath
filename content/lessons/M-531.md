# Lesson M-531 — Quadratic reciprocity awareness

Part L. L. Number Theory · **Additional elementary number theory** · Medium

Prerequisites: `L.2-L.3`.


This lesson isolates **Quadratic reciprocity awareness** and trains it until it is automatic.

This is a Medium skill: it appears less often, but when it appears it is often a discriminator. Number theory is additional-topics / algebra: congruences, Euler, CRT.

## 1. Why this skill exists

If you cannot do **Quadratic reciprocity awareness**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

Quadratic reciprocity: for distinct odd primes $p,q$, $\bigl(\frac{p}{q}\bigr)\bigl(\frac{q}{p}\bigr)=(-1)^{(p-1)(q-1)/4}$. The exponent is odd iff both primes are $3\bmod 4$, in which case the symbols are opposite; otherwise they agree. Combined with the supplementary laws for $-1$ and $2$, this computes Legendre symbols by descent.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Compute $\bigl(\frac{5}{13}\bigr)$ by reciprocity.

**Solution.** Both $1\bmod 4$, so $\bigl(\frac{5}{13}\bigr)=\bigl(\frac{13}{5}\bigr)=\bigl(\frac{3}{5}\bigr)$. Now $5\equiv 1\bmod 4$, $\bigl(\frac{3}{5}\bigr)=\bigl(\frac{5}{3}\bigr)=\bigl(\frac{2}{3}\bigr)$. $3\equiv 3\pmod{8}$, $\bigl(\frac{2}{3}\bigr)=-1$. So $\bigl(\frac{5}{13}\bigr)=-1$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $\bigl(\frac{3}{7}\bigr)\bigl(\frac{7}{3}\bigr)$ equals

**Solution.** $-1$, because both primes are $3\bmod 4$. And $\bigl(\frac{7}{3}\bigr)=\bigl(\frac{1}{3}\bigr)=1$, so $\bigl(\frac{3}{7}\bigr)=-1$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Flipping symbols when one prime is $1\bmod 4$ (no sign change then).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Does $\bigl(\frac{7}{11}\bigr)=\bigl(\frac{11}{7}\bigr)$?

**Solution.** No: both $3\bmod 4$, they are opposite. $\bigl(\frac{11}{7}\bigr)=\bigl(\frac{4}{7}\bigr)=1$, so $\bigl(\frac{7}{11}\bigr)=-1$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Evaluate $\bigl(\frac{13}{17}\bigr)$.

**Solution.** Both $1\bmod 4$: $=\bigl(\frac{17}{13}\bigr)=\bigl(\frac{4}{13}\bigr)=1$.

## 9. Lock it in

You own this skill when you can do Drill 1 and Drill 2 tomorrow, mixed among unrelated problems, in under five minutes each, with the traps named in Section 7 avoided on purpose.
