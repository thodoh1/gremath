# Lesson M-370 — Conservative vector fields

Part I. I. Vector Calculus · **Line integrals** · High

Prerequisites: `I.1`.


This lesson isolates **Conservative vector fields** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Vector calculus (Green/Stokes/divergence) appears less often than single-variable calculus but is a high-leverage discriminator.

## 1. Why this skill exists

If you cannot do **Conservative vector fields**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Line integrals*

Scalar line integrals weight by arc length. Vector line integrals measure work $\int_C\mathbf{F}\cdot d\mathbf{r}$. Conservative fields are gradients: path independence, $\mathbf{F}=\nabla f$, curl zero (on simply connected domains).

### This skill, specifically

Scalar line integrals weight by arc length.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

$\mathbf{F}$ is conservative on an open set $U$ if $\mathbf{F}=\nabla f$ for some $C^1$ scalar $f$ on $U$. Then $\int_C\mathbf{F}\cdot d\mathbf{r}$ depends only on endpoints. On a simply connected $U\subset\mathbb{R}^2$ or $\mathbb{R}^3$, this is equivalent to $\mathrm{curl}\,\mathbf{F}=\mathbf{0}$ (i.e. $P_y=Q_x$ in the plane).

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Is $\mathbf{F}=(2x,2y)$ conservative on $\mathbb{R}^2$? Is $\mathbf{F}=(-y,x)$?

**Solution.** Yes: $f=x^2+y^2$. No: $Q_x-P_y=2\neq 0$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** If $\mathrm{curl}\,\mathbf{F}=\mathbf{0}$ on $\mathbb{R}^3$, then $\mathbf{F}$ is

**Solution.** conservative (star-shaped/simply connected).

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Declaring $\mathbf{F}=(-y/(x^2+y^2),x/(x^2+y^2))$ conservative on the punctured plane because its curl vanishes there.
- Skip checking a candidate in the original equation.
