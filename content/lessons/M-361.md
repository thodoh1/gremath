# Lesson M-361 — Vector-valued functions

Part I. I. Vector Calculus · **Vector fields** · High

Prerequisites: `H.2`.


This lesson isolates **Vector-valued functions** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Vector calculus (Green/Stokes/divergence) appears less often than single-variable calculus but is a high-leverage discriminator.

## 1. Why this skill exists

If you cannot do **Vector-valued functions**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Vector fields*

A vector field assigns a vector to each point. Gradients are special fields. Velocity and acceleration are derivatives of vector-valued paths.

### This skill, specifically

A vector field assigns a vector to each point.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

A vector-valued function $\mathbf{r}:I\to\mathbb{R}^n$ assigns to each $t$ a vector $\mathbf{r}(t)=(x_1(t),\ldots,x_n(t))$. It is differentiable iff each component is, and $\mathbf{r}'=(x_1',\ldots,x_n')$. The graph is a parametrized curve.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** For $\mathbf{r}(t)=(t^2,4t-1,t^3)$, compute $\mathbf{r}(2)$ and $\mathbf{r}'(2)$.

**Solution.** $\mathbf{r}(2)=(4,7,8)$. $\mathbf{r}'(t)=(2t,4,3t^2)$, so $\mathbf{r}'(2)=(4,4,12)$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** If $\mathbf{r}(t)=(e^{2t},\sin 3t)$, then $\mathbf{r}'(0)$ equals

**Solution.** $(2,3)$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Differentiating the magnitude $|\mathbf{r}|$ in place of differentiating componentwise.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** $\mathbf{r}(t)=(3\cos t,3\sin t)$. Find $\mathbf{r}(\pi/2)$.

**Solution.** $(0,3)$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Is $\mathbf{r}(t)=(t,|t|)$ differentiable at $t=0$?

**Solution.** No: the second component has a corner.

## 9. Lock it in

You own this skill when you can do Drill 1 and Drill 2 tomorrow, mixed among unrelated problems, in under five minutes each, with the traps named in Section 7 avoided on purpose.
