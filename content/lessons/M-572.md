# Lesson M-572 — First isomorphism theorem

Part M. M. Group Theory · **Homomorphisms & quotients** · High

Prerequisites: `M.3`.


This lesson isolates **First isomorphism theorem** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Group theory is the main abstract-algebra GRE diet: orders, Lagrange, homomorphisms.

## 1. Why this skill exists

If you cannot do **First isomorphism theorem**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Homomorphisms & quotients*

A homomorphism preserves the operation. Kernel is a normal subgroup. First isomorphism theorem: $G/\ker\phi\cong\mathrm{im}\,\phi$. Quotients exist precisely because of normality.

### This skill, specifically

A homomorphism preserves the operation.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

First isomorphism theorem: if $\phi:G\to K$ is a homomorphism, then $G/\ker\phi\cong\mathrm{im}\,\phi$, via $g\ker\phi\mapsto\phi(g)$. Strategy: to identify a quotient, exhibit a surjective hom with that kernel. Examples: $\mathbb{Z}/n\mathbb{Z}\cong$ image of $\mathbb{Z}\to\mathbb{Z}/n\mathbb{Z}$; $GL_n/SL_n\cong F^\times$; $S_n/A_n\cong\{\pm 1\}$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Identify $\mathbb{R}^\times/\{\pm 1\}$ using the first iso theorem.

**Solution.** Absolute value $|\,\cdot\,|:\mathbb{R}^\times\to\mathbb{R}_{>0}$ is a surjective hom with kernel $\{\pm 1\}$. So $\mathbb{R}^\times/\{\pm 1\}\cong\mathbb{R}_{>0}$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $S_n/A_n\cong$

**Solution.** $\mathbb{Z}/2\mathbb{Z}$ via sign.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Writing $G/\mathrm{im}\,\phi\cong\ker\phi$ (swapping kernel and image).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Quotient $\mathbb{Z}/6\mathbb{Z}\big/\langle 2\rangle$.

**Solution.** $\langle 2\rangle=\{0,2,4\}\cong\mathbb{Z}/3$, quotient order $2\cong\mathbb{Z}/2$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** det induces $GL_2(\mathbb{R})/SL_2(\mathbb{R})\cong$

**Solution.** $\mathbb{R}^\times$.

## 9. Lock it in

You own this skill when you can do Drill 1 and Drill 2 tomorrow, mixed among unrelated problems, in under five minutes each, with the traps named in Section 7 avoided on purpose.
