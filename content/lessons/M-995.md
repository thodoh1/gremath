## 1. Why this skill exists

If you cannot do **Analyze determinant/eigenvalue conditions**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

A parameter in a matrix is often tested by $\det(A-tI)=0$ (eigenvalues) or $\det A(t)=0$ (singular values of $t$). Rank drops when all $k\times k$ minors vanish. Characteristic polynomial $\det(A-\lambda I)$ is monic of degree $n$; trace is minus the $\lambda^{n-1}$ coefficient. For $2\times 2$, $\lambda^2-(\mathrm{tr})\lambda+\det=0$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** For which $k$ is $\begin{pmatrix}1&k\\ 2&4\end{pmatrix}$ singular?

**Solution.** $\det=4-2k=0$, so $k=2$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Eigenvalues of $\begin{pmatrix}0&t\\ t&0\end{pmatrix}$.

**Solution.** $\lambda=\pm t$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Solving $\det(A-tI)=t$ by accident, or using $\det A=0$ when asked for eigenvalues of $A$ (that only detects a zero eigenvalue).
- Skip checking a candidate in the original equation.
