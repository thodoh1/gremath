# Lesson M-703 — Logical equivalence

Part Q. Q. Logic, Sets & Proof · **Propositional logic** · High

Prerequisites: `A.1`.


This lesson isolates **Logical equivalence** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Logic and proof are how other items are worded. Counting and analysis both depend on quantifiers.

## 1. Why this skill exists

If you cannot do **Logical equivalence**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Propositional logic*

Propositions, $\land,\lor,\neg,\to,\leftrightarrow$, truth tables, tautology, contradiction, converse vs contrapositive, De Morgan. Implication is not the arrow in your heart; $P\to Q$ is false only when $P$ is true and $Q$ false.

### This skill, specifically

Propositions, $\land,\lor,\neg,\to,\leftrightarrow$, truth tables, tautology, contradiction, converse vs contrapositive, De Morgan.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

Formulas $A$ and $B$ are logically equivalent ($A\equiv B$) if they have the same truth value on every assignment, iff $A\leftrightarrow B$ is a tautology. Standard equivalences: $P\to Q\equiv\neg P\vee Q\equiv\neg(P\wedge\neg Q)$, double negation, De Morgan, distributivity, commutativity.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Show $P\to Q$ is equivalent to $\neg Q\to\neg P$.

**Solution.** Both fail only when $P$ is true and $Q$ is false. (Contrapositive.)

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $P\wedge(P\to Q)$ is equivalent to

**Solution.** $P\wedge Q$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Replacing a subformula by a formula that is not equivalent (algebraic cancellation that is not valid).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Is $P\to Q$ equivalent to $Q\to P$?

**Solution.** No (converse).

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Simplify $\neg\neg P$.

**Solution.** $P$.

## 9. Lock it in

You own this skill when you can do Drill 1 and Drill 2 tomorrow, mixed among unrelated problems, in under five minutes each, with the traps named in Section 7 avoided on purpose.
