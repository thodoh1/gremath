# Lesson M-993 — Count roots as a parameter varies

Part Y. Y. Mixed GRE Problem-Solving · **Parameter problems** · Critical

Prerequisites: `A.4-E.5-K.7-G.2`.


This lesson isolates **Count roots as a parameter varies** and trains it until it is automatic.

This is a Critical skill: it is used constantly, and a hole here leaks points all over the paper. This is not content weight; it is how every weighted item is actually scored under a clock.

## 1. Why this skill exists

If you cannot do **Count roots as a parameter varies**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Parameter problems*

Track how the number of roots, extrema, eigenvalues, or convergence depends on a parameter. Degenerate cases (zero leading coefficient, repeated roots) are often the point.

### This skill, specifically

Track how the number of roots, extrema, eigenvalues, or convergence depends on a parameter.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

To count real roots of $p_t(x)=0$ as a parameter $t$ varies, track discriminant, derivative (how many critical values), and sign charts. A cubic always has at least one real root; a quadratic has $0,1,2$ real roots according as $\Delta<0,=0,>0$. Graphical: number of intersections of $y=f(x)$ with $y=t$. At a repeated root, $p=p'=0$ simultaneously.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Number of real $x$ with $x^2+2tx+1=0$, as $t\in\mathbb{R}$ varies.

**Solution.** $\Delta=4t^2-4=4(t^2-1)$. Two distinct reals if $|t|>1$, one (double) if $|t|=1$, none if $|t|<1$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** How many real roots does $x^3-3x-t=0$ have? Critical points $x=\pm 1$, $f(\pm 1)=\mp 2-t$. Three distinct reals iff

**Solution.** $|t|<2$ (between the local max/min values $\pm 2$).

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Counting a double root as two or one inconsistently with the question’s wording (‘distinct’ vs ‘counted with multiplicity’).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** $e^{-x}=t$ for real $x$: number of solutions vs $t$.

**Solution.** $1$ if $t>0$, $0$ if $t\le 0$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** $(x-t)^2(x-1)=0$: number of distinct real roots as $t$ varies.

**Solution.** $2$ if $t\neq 1$, $1$ if $t=1$.

## 9. Lock it in

You own this skill when you can do Drill 1 and Drill 2 tomorrow, mixed among unrelated problems, in under five minutes each, with the traps named in Section 7 avoided on purpose.
