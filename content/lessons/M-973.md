# Lesson M-973 — Bisection method

Part X. X. Numerical Analysis · **Root finding** · Medium

Prerequisites: `E.3`.


This lesson isolates **Bisection method** and trains it until it is automatic.

This is a Medium skill: it appears less often, but when it appears it is often a discriminator. Numerical methods are additional topics: Newton, error, quadrature recognition.

## 1. Why this skill exists

If you cannot do **Bisection method**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

Bisection: if $f$ is continuous on $[a,b]$ and $f(a)f(b)<0$, there is a root in $(a,b)$ by IVT. At each step replace the endpoint where $f$ has the same sign as $f(m)$ at the midpoint $m$. After $n$ steps the interval length is $(b-a)/2^n$, so the absolute error is at most that. Convergence is linear with rate $1/2$, guaranteed but slow. Need not find a multiple root that does not change sign.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** $f(x)=x^3-x-1$ on $[1,2]$. After one bisection, the new interval?

**Solution.** $f(1)=-1<0$, $f(2)=5>0$, $m=1.5$, $f(1.5)=1.5^3-1.5-1=0.875>0$, so $[1,1.5]$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Error bound after $10$ bisections of an interval of length $1$.

**Solution.** $\le 2^{-10}=1/1024$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Starting bisection without a sign change, or expecting quadratic speed like Newton.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** How many bisections to guarantee error $<10^{-3}$ starting from length $1$?

**Solution.** $n$ with $2^{-n}<10^{-3}$, so $n\ge 10$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Does bisection find the root of $f(x)=(x-1)^2$ on $[0,2]$?

**Solution.** No sign change; the method as stated does not start.
