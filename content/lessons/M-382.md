# Lesson M-382 — Stokes theorem

Part I. I. Vector Calculus · **Integral theorems** · High

Prerequisites: `I.2-I.3`.


This lesson isolates **Stokes theorem** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Vector calculus (Green/Stokes/divergence) appears less often than single-variable calculus but is a high-leverage discriminator.

## 1. Why this skill exists

If you cannot do **Stokes theorem**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

Stokes' theorem: $\oint_{\partial S}\mathbf{F}\cdot d\mathbf{r}=\iint_S(\nabla\times\mathbf{F})\cdot d\mathbf{S}$ for an oriented surface with compatible boundary. The surface can be deformed if $\mathrm{curl}\,\mathbf{F}$ is defined in between (same boundary, same orientation).

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** $\mathbf{F}=(-y,x,0)$ on the unit hemisphere $z=\sqrt{1-x^2-y^2}$, boundary the unit equator, upward normal. Compute the flux of curl.

**Solution.** $\nabla\times\mathbf{F}=(0,0,2)$. Flux through the hemisphere equals flux through the unit disk: $2\pi$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** If $\nabla\times\mathbf{F}=\mathbf{0}$ on a simply connected region, $\oint_{\partial S}$ is

**Solution.** $0$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Integrating $\mathbf{F}$ over $S$ instead of $\mathrm{curl}\,\mathbf{F}$, or using an incompatible boundary orientation.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Stokes reduces to Green when $S$ is a plane region in $z=0$ and $\mathbf{F}=(P,Q,0)$.

**Solution.** True: $Q_x-P_y$ is the $z$-component of curl.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Can you replace a hemispherical $S$ by the disk with the same circle?

**Solution.** Yes, if $\mathrm{curl}\,\mathbf{F}$ is $C^1$ in the enclosed half-ball.
