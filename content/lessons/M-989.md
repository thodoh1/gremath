# Lesson M-989 — Identify the governing concept before calculating

Part Y. Y. Mixed GRE Problem-Solving · **Theorem/definition recognition** · Critical

Prerequisites: `A-Q`.


This lesson isolates **Identify the governing concept before calculating** and trains it until it is automatic.

This is a Critical skill: it is used constantly, and a hole here leaks points all over the paper. This is not content weight; it is how every weighted item is actually scored under a clock.

## 1. Why this skill exists

If you cannot do **Identify the governing concept before calculating**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

Before computing, name the object: IVT, EVT, MVT, rank-nullity, Cauchy–Schwarz, residue theorem, Bayes, or a definition (injective, eigenvalue, uniform convergence). Mixed GRE stems often look like calculus but are linear algebra, or look like algebra but are geometry. A 10-second classification prevents a 5-minute wrong expansion.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** ‘$f$ continuous on $[0,1]$, $f(0)=-1$, $f(1)=2$. Which must be true?’ Compute nothing: this is IVT. $f$ has a zero in $(0,1)$. EVT would need a max/min question; MVT would need differentiability.

**Solution.** IVT applies; a root exists. Differentiability was never given, so Rolle/MVT are unavailable.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $A$ is $3\times 3$ and $A\mathbf{v}=0$ for some $\mathbf{v}\neq\mathbf{0}$. Immediately

**Solution.** $A$ is singular, $\det A=0$, $0$ is an eigenvalue, columns are dependent — all one fact.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Starting to compute a basis of the kernel when the question only asked whether a nontrivial kernel exists.
- Skip checking a candidate in the original equation.
