# Lesson M-629 — Archimedean property

Part O. O. Real Analysis · **Real-number foundations** · High

Prerequisites: `A.1`.


This lesson isolates **Archimedean property** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Real analysis items are often ‘which statement is true?’ definition checks inside additional topics.

## 1. Why this skill exists

If you cannot do **Archimedean property**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Real-number foundations*

$\mathbb{R}$ is a complete ordered field: every nonempty set bounded above has a least upper bound. Suprema, infima, Archimedean property, density of $\mathbb{Q}$ and of irrationals, nested intervals.

### This skill, specifically

$\mathbb{R}$ is a complete ordered field: every nonempty set bounded above has a least upper bound.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

Archimedean property: for every real $x$ there is $n\in\mathbb{N}$ with $n>x$. Equivalently, $\{1/n:n\in\mathbb{N}\}$ has infimum $0$: for every $\varepsilon>0$ some $n$ has $1/n<\varepsilon$. Thus $\mathbb{N}$ is unbounded above in $\mathbb{R}$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Prove there is an integer $n$ with $n>100\pi$.

**Solution.** Archimedean: $\mathbb{N}$ is not bounded above, so some $n>100\pi$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Does there exist $n$ with $0<1/n<10^{-9}$?

**Solution.** Yes: take $n>10^9$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Thinking there is an infinite integer, or a smallest positive real.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Is there a largest integer?

**Solution.** No.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Why does $1/n\to 0$ need Archimedes?

**Solution.** To produce $N>1/\varepsilon$.

## 9. Lock it in

You own this skill when you can do Drill 1 and Drill 2 tomorrow, mixed among unrelated problems, in under five minutes each, with the traps named in Section 7 avoided on purpose.
