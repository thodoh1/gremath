# Lesson M-631 — Density of irrationals

Part O. O. Real Analysis · **Real-number foundations** · High

Prerequisites: `A.1`.


This lesson isolates **Density of irrationals** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Real analysis items are often ‘which statement is true?’ definition checks inside additional topics.

## 1. Why this skill exists

If you cannot do **Density of irrationals**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Real-number foundations*

$\mathbb{R}$ is a complete ordered field: every nonempty set bounded above has a least upper bound. Suprema, infima, Archimedean property, density of $\mathbb{Q}$ and of irrationals, nested intervals.

### This skill, specifically

$\mathbb{R}$ is a complete ordered field: every nonempty set bounded above has a least upper bound.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

Density of irrationals: if $a<b$, there is an irrational $x$ with $a<x<b$. Construction: choose a rational $q$ in $(a-\sqrt{2},b-\sqrt{2})$, then $q+\sqrt{2}$ is irrational and lies in $(a,b)$. Equivalently, $\mathbb{R}\setminus\mathbb{Q}$ is dense.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Produce an irrational in $(0,1/100)$.

**Solution.** $\sqrt{2}/200$ works: $0<\sqrt{2}/200<1.5/200<1/100$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Is there an irrational between $3$ and $3.0001$?

**Solution.** Yes, e.g. $3+\sqrt{2}/10^5$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Thinking irrationals are sparse because each has a complicated expansion.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Are the irrationals countable?

**Solution.** No: $\mathbb{R}$ uncountable and $\mathbb{Q}$ countable, so the complement is uncountable.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** $q+\sqrt{2}$ for $q\in\mathbb{Q}$ is always

**Solution.** irrational.
