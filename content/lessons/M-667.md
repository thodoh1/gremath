# Lesson M-667 — Fundamental theorem

Part O. O. Real Analysis · **Differentiability & integration** · High

Prerequisites: `E.3-O.4`.


This lesson isolates **Fundamental theorem** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Real analysis items are often ‘which statement is true?’ definition checks inside additional topics.

## 1. Why this skill exists

If you cannot do **Fundamental theorem**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

Fundamental theorem: if $f$ is integrable on $[a,b]$ and $F(x)=\int_a^x f$, then $F$ is continuous; if $f$ is continuous at $c$, then $F'(c)=f(c)$. Conversely, if $F'=f$ is integrable, $\int_a^b f=F(b)-F(a)$. Chain rule form: $\frac{d}{dx}\int_{u(x)}^{v(x)}f=f(v)v'-f(u)u'$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Differentiate $\int_0^{x^2}\sin t\,dt$.

**Solution.** $2x\sin(x^2)$ by FTC and chain rule.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $\int_0^\pi \cos t\,dt$ equals

**Solution.** $\sin\pi-\sin 0=0$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Differentiating under the integral sign while forgetting the chain-rule factor from variable limits.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** If $F'=f$ continuous, $\int_1^2 f$ in terms of $F$.

**Solution.** $F(2)-F(1)$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Is $F(x)=\int_0^x 1_{\mathbb{Q}}$ differentiable?

**Solution.** $1_{\mathbb{Q}}$ is not integrable, so $F$ is not defined as a Riemann integral. For an integrable discontinuous $f$, $F'$ need not equal $f$ everywhere.
