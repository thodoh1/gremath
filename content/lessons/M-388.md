# Lesson M-388 — Order and linearity

Part J. J. Differential Equations · **First-order ODEs** · High

Prerequisites: `F.1-E.3`.


This lesson isolates **Order and linearity** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. ODEs appear as additional or calculus-adjacent items: separable, linear first order, characteristic equations.

## 1. Why this skill exists

If you cannot do **Order and linearity**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *First-order ODEs*

Classify, then solve: separable, linear (integrating factor), exact, Bernoulli, autonomous equilibria and stability, logistic. IVPs pick the constant.

### This skill, specifically

Classify, then solve: separable, linear (integrating factor), exact, Bernoulli, autonomous equilibria and stability, logistic.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

The order of an ODE is the highest derivative present. It is linear if it has the form $a_n(x)y^{(n)}+\cdots+a_1(x)y'+a_0(x)y=g(x)$ (unknown and derivatives appear to the first power, no products of $y,y',\ldots$). Superposition holds only for linear homogeneous equations.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Orders and linearity of $y y''+y'=0$ and $y''+3y'+2y=\sin x$.

**Solution.** First is second-order nonlinear (product $y y''$). Second is second-order linear nonhomogeneous.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $y'+y^2=x$ is

**Solution.** first-order nonlinear.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Calling $y''+y y'=0$ linear because it is first-degree in $y''$ (the $y y'$ term kills linearity).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Order of $y'''-x y=0$.

**Solution.** $3$, linear homogeneous.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Is $y'=\sin y$ linear?

**Solution.** No.
