# Lesson M-986 — Euler method for ODEs

Part X. X. Numerical Analysis · **Numerical integration & ODEs** · Medium

Prerequisites: `F.2-J.1`.


This lesson isolates **Euler method for ODEs** and trains it until it is automatic.

This is a Medium skill: it appears less often, but when it appears it is often a discriminator. Numerical methods are additional topics: Newton, error, quadrature recognition.

## 1. Why this skill exists

If you cannot do **Euler method for ODEs**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

Euler’s method for $y'=f(t,y)$, $y(t_0)=y_0$, step $h$: $y_{n+1}=y_n+h f(t_n,y_n)$, $t_{n+1}=t_n+h$. Local truncation $O(h^2)$; global error $O(h)$ on a fixed interval (consistent order $1$). It follows the tangent field. Unstable for stiff $y'=\lambda y$ with $\mathrm{Re}\,\lambda<0$ unless $|1+h\lambda|\le 1$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Euler on $y'=y$, $y(0)=1$, $h=1$, one step.

**Solution.** $y_1=1+1\cdot 1=2$, while $e^1=e\approx 2.718$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 7. Traps that cost points

- Using $f(t_{n+1},y_{n+1})$ as if it were implicit Euler without solving, or expecting $O(h^2)$ global error.
- Skip checking a candidate in the original equation.
