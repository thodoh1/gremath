## 3. Precise statement

Depth-first search (DFS) explores as far as possible along each branch before backtracking (stack / recursion). It produces a DFS forest, classifying edges as tree, back, forward, or cross. DFS decides cycle existence: a back edge in an undirected graph means a cycle. Also $O(|V|+|E|)$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 5. Worked example

**Problem.** DFS on a tree. Back edges?

**Solution.** None: a tree has no extra edges.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Undirected $C_5$: DFS finds a cycle because

**Solution.** the last vertex has an edge back to an ancestor on the stack.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Claiming DFS layers equal distances (that is BFS). DFS visit order depends on adjacency-list order.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Connected undirected graph, DFS from $s$ produces how many trees in the DFS forest?

**Solution.** One (the component of $s$); remaining components give additional trees if you restart.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Space in the recursive implementation is $O($what$)$ in the worst case on a path.

**Solution.** $O(n)$ recursion depth.
