# Lesson M-665 — Riemann integrability

Part O. O. Real Analysis · **Differentiability & integration** · High

Prerequisites: `E.3-O.4`.


This lesson isolates **Riemann integrability** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Real analysis items are often ‘which statement is true?’ definition checks inside additional topics.

## 1. Why this skill exists

If you cannot do **Riemann integrability**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

A bounded $f:[a,b]\to\mathbb{R}$ is Riemann integrable iff the upper and lower Darboux sums can be made arbitrarily close: for every $\varepsilon>0$ some partition has $U(f,P)-L(f,P)<\varepsilon$. Lebesgue's criterion: iff the set of discontinuities has measure zero. The Dirichlet function $1_{\mathbb{Q}}$ is not integrable on $[0,1]$; Thomae's function is.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Why is $1_{\mathbb{Q}}$ not Riemann integrable on $[0,1]$?

**Solution.** On every subinterval, $\sup f=1$ and $\inf f=0$, so $U-L=1$ for every partition.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** A bounded function with a single jump is integrable?

**Solution.** Yes: one discontinuity, measure zero.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Claiming every bounded function is Riemann integrable, or that pointwise discontinuities always block integrability.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Is the step function $1_{[0,1/2]}$ integrable on $[0,1]$?

**Solution.** Yes: discontinuous only at $1/2$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Thomae's function is integrable because it is continuous a.e.: where?

**Solution.** Continuous at irrationals, discontinuous at rationals (countable).
