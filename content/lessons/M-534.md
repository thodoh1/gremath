# Lesson M-534 — Möbius inversion

Part L. L. Number Theory · **Additional elementary number theory** · Medium

This lesson isolates **Möbius inversion** and trains it until it is automatic.

## 3. Precise statement

Möbius inversion: if $g(n)=\sum_{d\mid n}f(d)$ for all $n$, then $f(n)=\sum_{d\mid n}\mu(d)g(n/d)=\sum_{d\mid n}\mu(n/d)g(d)$. Classic: $n=\sum_{d\mid n}\phi(d)$ inverts to $\phi(n)=\sum_{d\mid n}\mu(d)\,n/d$. The Dirichlet convolution identity is $f=g*\mu$ when $g=f*1$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

## 5. Worked example

**Problem.** Recover $\phi(10)$ from $n=\sum_{d\mid n}\phi(d)$ by inversion.

**Solution.** $\phi(10)=\sum_{d\mid 10}\mu(d)\cdot 10/d=\mu(1)10+\mu(2)5+\mu(5)2+\mu(10)1=10-5-2+1=4$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 7. Traps that cost points

- Summing $f(d)g(n/d)$ without the $\mu$ factor, or inverting only over primes.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Invert $d(n)=\sum_{d\mid n}1$ to get $1$ at $n=1$ and $0$ else: the formula is

**Solution.** $\sum_{d\mid n}\mu(d)$, which is $0$ for $n>1$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Write $\phi(p^k)$ by inversion.

**Solution.** $\mu(1)p^k+\mu(p)p^{k-1}=p^k-p^{k-1}$.
