# Lesson M-342 — Chain rule in several variables

Part H. H. Multivariable Calculus · **Differentiability** · High

Prerequisites: `H.1-K.4`.


This lesson isolates **Chain rule in several variables** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Multivariable calculus is explicitly in the calculus portion: partials, gradients, multiple integrals, Jacobians.

## 1. Why this skill exists

If you cannot do **Chain rule in several variables**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Differentiability*

Existence of partials is not differentiability. The derivative is a linear map (Jacobian). Directional derivatives are $\nabla f\cdot u$. The chain rule in several variables is matrix multiplication of Jacobians.

### This skill, specifically

Existence of partials is not differentiability.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

Chain rule: if $\mathbf{x}(t)$ is a path and $f$ is differentiable, $\frac{d}{dt}f(\mathbf{x}(t))=\nabla f\cdot\mathbf{x}'(t)$. More generally $D(f\circ G)=(Df)(DG)$ as matrices. Tree diagrams help with $z=z(x,y)$, $x=x(s,t)$, $y=y(s,t)$: $z_s=z_x x_s+z_y y_s$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** $z=x^2+y^2$, $x=\cos t$, $y=\sin t$. $dz/dt$.

**Solution.** $\nabla z\cdot(-sin t,\cos t)=(2x,2y)\cdot(-\sin t,\cos t)=0$ (constant on the circle).

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $z=xy$, $x=s+t$, $y=st$, $z_s$

**Solution.** $y\cdot 1+x\cdot t=(st)+t(s+t)=2st+t^2$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Forgetting a branch of the tree (missing a product).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** $f=e^{x}y$, $x=t$, $y=t^2$, $f'(t)$.

**Solution.** $e^{t}t^2+e^{t}(2t)$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** On a level curve $f(\mathbf{x}(t))=c$, $\nabla f\cdot\mathbf{x}'=$

**Solution.** $0$.
