# Lesson M-739 — Equivalence classes

Part Q. Q. Logic, Sets & Proof · **Set theory** · High

Prerequisites: `Q.1-Q.3`.


This lesson isolates **Equivalence classes** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Logic and proof are how other items are worded. Counting and analysis both depend on quantifiers.

## 1. Why this skill exists

If you cannot do **Equivalence classes**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

The equivalence class of $a$ is $[a]=\{x:x\sim a\}$. Then $a\sim b$ iff $[a]=[b]$, and distinct classes are disjoint. The quotient $A/{\sim}$ is the set of classes. In $\mathbb{Z}/n\mathbb{Z}$ there are $n$ classes, written $\overline{0},\ldots,\overline{n-1}$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** For $a\equiv b\pmod 2$ on $\mathbb{Z}$, describe $[0]$ and $[1]$.

**Solution.** Evens; odds. These are the only two classes.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $[a]=[b]$ iff

**Solution.** $a\sim b$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Thinking two classes can overlap in some but not all elements (they cannot).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** How many distinct classes for ``same fractional part'' on $\mathbb{R}$ (i.e. $x-y\in\mathbb{Z}$)?

**Solution.** One per residue in $[0,1)$: uncountably many, parametrized by $[0,1)$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** The quotient map $a\mapsto[a]$ is

**Solution.** a surjection $A\to A/{\sim}$.
