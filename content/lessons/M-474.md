# Lesson M-474 — Determinant-zero criterion for invertibility

Part K. K. Linear Algebra · **Determinants** · Critical

Prerequisites: `K.2-K.4`.


This lesson isolates **Determinant-zero criterion for invertibility** and trains it until it is automatic.

This is a Critical skill: it is used constantly, and a hole here leaks points all over the paper. Linear algebra is a large share of the algebra portion. Rank, kernels, eigenvalues, and determinants are exam staples.

## 1. Why this skill exists

If you cannot do **Determinant-zero criterion for invertibility**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Determinants*

Det is an alternating multilinear form, computable by cofactors or row ops. $\det(AB)=\det A\det B$, $\det A\neq 0$ iff invertible, geometry as signed volume, Cramer’s rule as a museum piece that still appears.

### This skill, specifically

Det is an alternating multilinear form, computable by cofactors or row ops.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

A square matrix $A$ is invertible iff $\det A\neq 0$ iff $0$ is not an eigenvalue iff $\mathrm{Nul}\,A=\{\mathbf{0}\}$ iff $\mathrm{rank}\,A=n$. Any one of these failing implies all fail. This is the determinant-zero criterion used constantly on the GRE.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Is $\begin{pmatrix}1&2\\2&4\end{pmatrix}$ invertible? Why via det?

**Solution.** $\det=0$, not invertible (columns dependent).

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $A$ singular means

**Solution.** $\det A=0$, not invertible.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Declaring $A$ invertible because all entries are nonzero, or because the diagonal is nonzero (false for $\begin{pmatrix}1&1\\1&1\end{pmatrix}$).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** $\det(A-\lambda I)=0$ is the condition that

**Solution.** $\lambda$ is an eigenvalue.

**Drill 2.** If $\det A\neq 0$, the system $A\mathbf{x}=\mathbf{b}$ has

**Solution.** a unique solution for every $\mathbf{b}$.
