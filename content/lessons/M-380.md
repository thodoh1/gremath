# Lesson M-380 — Recognizing conservative fields

Part I. I. Vector Calculus · **Curl, divergence & flux** · High

Prerequisites: `I.1-H.2`.


This lesson isolates **Recognizing conservative fields** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Vector calculus (Green/Stokes/divergence) appears less often than single-variable calculus but is a high-leverage discriminator.

## 1. Why this skill exists

If you cannot do **Recognizing conservative fields**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Curl, divergence & flux*

Div is source density; curl is local rotation; flux is flow through a surface. Orientation is a sign convention you must not treat as optional.

### This skill, specifically

Div is source density; curl is local rotation; flux is flow through a surface.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

To recognize a conservative field: (i) check $\mathrm{curl}\,\mathbf{F}=\mathbf{0}$; (ii) confirm the domain is simply connected (or star-shaped); (iii) construct $f$ by integration. In $\mathbb{R}^2$ the test is $P_y=Q_x$. Failure of (i) is conclusive non-conservativeness; failure of (ii) is a warning.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Which of $(2x,2y)$, $(-y,x)$, $(-y/r^2,x/r^2)$ on their natural domains are conservative?

**Solution.** First yes on $\mathbb{R}^2$. Second no (curl $2$). Third curl $0$ off the origin but not conservative on $\mathbb{R}^2\setminus\{\mathbf{0}\}$ (circulation $2\pi$).

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** If $P_y=Q_x$ on a disk, $\mathbf{F}$ is

**Solution.** conservative there.

## 7. Traps that cost points

- Stopping at $\mathrm{curl}=\mathbf{0}$ for a field defined only on an annulus and concluding path independence.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Is $(3x^2 y,x^3)$ conservative on $\mathbb{R}^2$?

**Solution.** Yes: $f=x^3 y$.

Cover that solution, redo the drill on paper, then continue.
