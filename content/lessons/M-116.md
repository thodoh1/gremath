# Lesson M-116 — Symmetry in polar graphs

Part B. B. Precalculus & Functions · **Parametric & polar basics** · High

Prerequisites: `C.1; B.1`.


This lesson isolates **Symmetry in polar graphs** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Functions and precalculus appear inside calculus items constantly: domains of compositions, inverses, piecewise definitions, sequences.

## 1. Why this skill exists

If you cannot do **Symmetry in polar graphs**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Parametric & polar basics*

Parametric equations describe a curve by $x(t),y(t)$. Polar coordinates describe a point by radius and angle. Eliminating $t$ recovers a Cartesian relation when you need it; keeping $t$ is better for motion. Polar area uses $\frac12\int r^2\,d\theta$.

### This skill, specifically

Parametric equations describe a curve by $x(t),y(t)$.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

Polar symmetry: if $f(\theta)=f(-\theta)$, symmetry about the polar axis. If $f(\pi-\theta)=f(\theta)$, about $\theta=\pi/2$. If $f(\theta+\pi)=f(\theta)$, symmetry about the pole (or $r\mapsto -r$).

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** $r=\cos(2\theta)$ has symmetry about

**Solution.** both axes and the pole.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $r=1+\sin\theta$ is symmetric about

**Solution.** the $y$-axis.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Testing only $r(\theta)=r(-\theta)$ and missing $r(\theta)=r(\pi-\theta)$.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Does $r=\theta$ (spiral) have polar-axis symmetry?

**Solution.** No.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** $r^2=\sin(2\theta)$ is a lemniscate; symmetry?

**Solution.** About $y=x$ and the origin.
