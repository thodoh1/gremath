## 3. Precise statement

To test an identity or a formula claimed for all $n$ (or all matrices, all $x$), substitute a convenient special case: $n=1$, $x=0$, $A=I$, $t=0$, a $1\times 1$ matrix, an equilateral triangle. If the identity fails on the special case, it is false. If it holds, you have not proved it, but you have eliminated distractors. Homogeneous formulas can be tested by scaling.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 5. Worked example

**Problem.** A claimed formula $\sum_{k=1}^n k=n^2/2$. Test $n=1$.

**Solution.** $1\neq 1/2$. False. (The true formula is $n(n+1)/2$.)

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Claim: $\det(A+B)=\det A+\det B$ for all $2\times 2$. Test $A=B=I$.

**Solution.** $4\neq 1+1$. False.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Using a special case that lies in a degenerate subclass where a false identity accidentally holds (testing $\det(A+B)=\det A+\det B$ on $B=0$).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Claim $\cos 2\theta=2\cos\theta$. Test $\theta=0$.

**Solution.** $\cos 0=1$ but $2\cos 0=2$. False already.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Claim: every group of order $4$ is cyclic. Test the Klein group $\{e,a,b,ab\}$ with all non-identity elements order $2$.

**Solution.** Counterexample; the claim is false.
