# Lesson M-453 — Coordinates relative to a basis

Part K. K. Linear Algebra · **Vector spaces** · Critical

Prerequisites: `K.1-K.3`.


This lesson isolates **Coordinates relative to a basis** and trains it until it is automatic.

This is a Critical skill: it is used constantly, and a hole here leaks points all over the paper. Linear algebra is a large share of the algebra portion. Rank, kernels, eigenvalues, and determinants are exam staples.

## 1. Why this skill exists

If you cannot do **Coordinates relative to a basis**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

## 3. Precise statement

If $\mathcal{B}=\{\mathbf{b}_1,\ldots,\mathbf{b}_n\}$ is a basis, the coordinates $[\mathbf{v}]_{\mathcal{B}}=\mathbf{c}$ are the unique scalars with $\mathbf{v}=c_1\mathbf{b}_1+\cdots+c_n\mathbf{b}_n$. If $P$ has columns $\mathbf{b}_j$ (in the standard basis), then $\mathbf{v}=P[\mathbf{v}]_{\mathcal{B}}$. Changing $\mathcal{B}$ changes the coordinate tuple, not $\mathbf{v}$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** $\mathbf{v}=(5,1)$, $\mathcal{B}=\{(1,1),(1,-1)\}$. Find $[\mathbf{v}]_{\mathcal{B}}$.

**Solution.** $a(1,1)+b(1,-1)=(5,1)$ $\Rightarrow$ $a+b=5$, $a-b=1$, so $a=3$, $b=2$. Coordinates $\begin{pmatrix}3\\2\end{pmatrix}$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $[\mathbf{e}_1]_{\mathcal{E}}$ in the standard basis is

**Solution.** $\begin{pmatrix}1\\0\end{pmatrix}$ in $\mathbb{R}^2$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Solving $P\mathbf{c}=\mathbf{v}$ but reporting $P\mathbf{v}$ as the coordinates.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Coordinates of $3+2x$ in $\{1,x\}$ for $P_1$.

**Solution.** $(3,2)$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** If $[\mathbf{v}]_{\mathcal{B}}=\mathbf{0}$, then $\mathbf{v}$ is

**Solution.** the zero vector.
