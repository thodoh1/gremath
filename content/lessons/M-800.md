# Lesson M-800 — Hamiltonian paths

Part S. S. Graph Theory & Algorithms · **Special graph classes** · Medium

Prerequisites: `S.1`.


This lesson isolates **Hamiltonian paths** and trains it until it is automatic.

This is a Medium skill: it appears less often, but when it appears it is often a discriminator. Graph theory is additional topics: trees, Euler, handshaking, planarity.

## 1. Why this skill exists

If you cannot do **Hamiltonian paths**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Special graph classes*

### This skill, specifically

$K_n$, bipartite (including trees), rooted trees, leaves, spanning trees, Euler vs Hamilton.

## 3. Precise statement

A Hamiltonian path visits every vertex exactly once (not necessarily all edges). There is no simple local degree criterion analogous to Euler's theorem; existence is NP-complete in general. Sufficient conditions (Dirac: $\delta\ge n/2$; Ore: $\deg u+\deg v\ge n$ for nonadjacent $u,v$) are not necessary.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Does $K_{2,3}$ have a Hamiltonian path? Hamiltonian cycle?

**Solution.** Path yes (alternate parts; the parts differ by $1$). Cycle no: bipartite with unequal parts.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Dirac on $n=7$: $\delta\ge$ how much guarantees a Hamiltonian cycle?

**Solution.** $\delta\ge 3.5$, so $\delta\ge 4$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Applying the Euler even-degree test to Hamiltonian questions, or claiming every tree has a Hamiltonian path (only paths do, among trees).
- Skip checking a candidate in the original equation.
