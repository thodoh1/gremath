# Lesson M-387 — ODE terminology

Part J. J. Differential Equations · **First-order ODEs** · High

Prerequisites: `F.1-E.3`.


This lesson isolates **ODE terminology** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. ODEs appear as additional or calculus-adjacent items: separable, linear first order, characteristic equations.

## 1. Why this skill exists

If you cannot do **ODE terminology**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *First-order ODEs*

Classify, then solve: separable, linear (integrating factor), exact, Bernoulli, autonomous equilibria and stability, logistic. IVPs pick the constant.

### This skill, specifically

Classify, then solve: separable, linear (integrating factor), exact, Bernoulli, autonomous equilibria and stability, logistic.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

An ODE relates an unknown function $y(x)$ to its derivatives: $F(x,y,y',\ldots,y^{(n)})=0$. The independent variable is $x$; $y$ is dependent. A solution on an interval is a $C^n$ function satisfying the equation identically. A family with arbitrary constants is a general solution.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Classify $x\dfrac{dy}{dx}+2y=e^x$ as an ODE, and name independent/dependent variables.

**Solution.** First-order ODE in $y(x)$; independent $x$, dependent $y$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Is $y''=y^2$ an ODE?

**Solution.** Yes, second-order, nonlinear.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Calling $u_{xx}+u_{yy}=0$ an ODE (it is a PDE: two independent variables).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Does $y=e^{2x}$ solve $y'=2y$?

**Solution.** Yes: both sides $2e^{2x}$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** How many independent variables in $y'(t)=3y(t)$?

**Solution.** One ($t$).

## 9. Lock it in

You own this skill when you can do Drill 1 and Drill 2 tomorrow, mixed among unrelated problems, in under five minutes each, with the traps named in Section 7 avoided on purpose.
