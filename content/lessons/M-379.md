# Lesson M-379 — Basic vector identities

Part I. I. Vector Calculus · **Curl, divergence & flux** · High

Prerequisites: `I.1-H.2`.


This lesson isolates **Basic vector identities** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Vector calculus (Green/Stokes/divergence) appears less often than single-variable calculus but is a high-leverage discriminator.

## 1. Why this skill exists

If you cannot do **Basic vector identities**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Curl, divergence & flux*

Div is source density; curl is local rotation; flux is flow through a surface. Orientation is a sign convention you must not treat as optional.

### This skill, specifically

Div is source density; curl is local rotation; flux is flow through a surface.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

Standard $C^2$ identities: $\nabla\times(\nabla f)=\mathbf{0}$, $\nabla\cdot(\nabla\times\mathbf{F})=0$, $\nabla\cdot(\nabla f)=\Delta f$, $\nabla\times(\nabla\times\mathbf{F})=\nabla(\nabla\cdot\mathbf{F})-\Delta\mathbf{F}$, and product rules such as $\nabla\cdot(f\mathbf{F})=\nabla f\cdot\mathbf{F}+f\nabla\cdot\mathbf{F}$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Verify $\nabla\cdot(\nabla\times(yz,xz,xy))$.

**Solution.** Curl is $\mathbf{0}$, divergence $0$. Directly: each identity applies.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

**Problem.** $\Delta(x^2+y^2+z^2)$ equals

**Solution.** $6$.

## 7. Traps that cost points

- Using $\nabla\times(\nabla\times\mathbf{F})=\mathbf{0}$ as if it were always true (it is not: take $\mathbf{F}=(0,0,x^2)$).
- Skip checking a candidate in the original equation.
