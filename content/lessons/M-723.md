# Lesson M-723 — Mathematical induction

Part Q. Q. Logic, Sets & Proof · **Proof methods** · High

Prerequisites: `Q.2`.


This lesson isolates **Mathematical induction** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Logic and proof are how other items are worded. Counting and analysis both depend on quantifiers.

## 1. Why this skill exists

If you cannot do **Mathematical induction**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Proof methods*

Direct, contrapositive, contradiction, cases, counterexample, existence, uniqueness, induction, strong induction, well-ordering. Pick the method from the logical shape of the claim.

### This skill, specifically

Direct, contrapositive, contradiction, cases, counterexample, existence, uniqueness, induction, strong induction, well-ordering.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

Mathematical induction: to prove $P(n)$ for all integers $n\ge n_0$, prove $P(n_0)$ (base) and $\forall k\ge n_0,\, (P(k)\to P(k+1))$ (successor). Equivalent to well-ordering. The inductive hypothesis $P(k)$ is an assumption for that step, not the theorem.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Prove $\sum_{k=1}^n k=n(n+1)/2$ by induction.

**Solution.** Base $n=1$: $1=1$. If true for $k$, then $\sum^{k+1}=k(k+1)/2+(k+1)=(k+1)(k+2)/2$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Base case can start at $n_0=0$ or $n=2$ if needed: true?

**Solution.** True: the statement is only claimed from $n_0$ on.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Using $P(k+1)$ inside the proof of $P(k+1)$, or skipping a valid base (e.g. all horses the same color).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Inductive step for $2^n\ge n+1$, $n\ge 0$.

**Solution.** $2^{k+1}=2\cdot 2^k\ge 2(k+1)=2k+2\ge k+2$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Does induction prove $P(n)$ for real $n$?

**Solution.** No: only along the integers from the base.

## 9. Lock it in

You own this skill when you can do Drill 1 and Drill 2 tomorrow, mixed among unrelated problems, in under five minutes each, with the traps named in Section 7 avoided on purpose.
