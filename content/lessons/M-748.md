# Lesson M-748 — Countably infinite sets

Part Q. Q. Logic, Sets & Proof · **Functions & cardinality** · High

Prerequisites: `Q.4`.


This lesson isolates **Countably infinite sets** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Logic and proof are how other items are worded. Counting and analysis both depend on quantifiers.

## 1. Why this skill exists

If you cannot do **Countably infinite sets**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Functions & cardinality*

Injection, surjection, bijection, composition, inverses. Countable vs uncountable, Cantor diagonal, $|\mathbb{N}|=|\mathbb{Z}|=|\mathbb{Q}|<|\mathbb{R}|$, axiom of choice as awareness.

### This skill, specifically

Injection, surjection, bijection, composition, inverses.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

A set is countably infinite (denumerable) if it is in bijection with $\mathbb{N}$, i.e. cardinality $\aleph_0$. Hilbert's hotel: $\aleph_0+1=\aleph_0$ and $\aleph_0+\aleph_0=\aleph_0$. Cantor pairing: $\mathbb{N}\times\mathbb{N}\cong\mathbb{N}$. $\mathbb{Q}\cong\mathbb{N}$. An infinite subset of a countably infinite set is countably infinite.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Give an explicit bijection $\mathbb{N}\times\mathbb{N}\to\mathbb{N}$ (or an injection both ways).

**Solution.** Pairing $(m,n)\mapsto 2^m(2n+1)-1$, or diagonal enumeration. Injections: $(m,n)\mapsto 2^m 3^n$ and $k\mapsto(k,1)$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Hilbert hotel: a hotel with $\aleph_0$ full rooms can still accommodate one more guest by

**Solution.** $n\mapsto n+1$, freeing room $1$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Calling $\mathbb{R}$ countably infinite, or thinking removing one point from $\mathbb{N}$ changes cardinality.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** $|\mathbb{N}|$, $|\mathbb{Z}|$, $|\mathbb{Q}|$ compared.

**Solution.** All equal $\aleph_0$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Even naturals vs $\mathbb{N}$.

**Solution.** Bijection $n\mapsto 2n$; same cardinality.
