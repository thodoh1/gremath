# Lesson M-896 — Basic regression inference

Part U. U. Mathematical Statistics · **Inference** · Medium

Prerequisites: `U.1-U.2`.


This lesson isolates **Basic regression inference** and trains it until it is automatic.

This is a Medium skill: it appears less often, but when it appears it is often a discriminator. Statistics is lighter than probability but bias, MLE, and tests do appear.

## 1. Why this skill exists

If you cannot do **Basic regression inference**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Inference*

CIs, hypothesis tests, Type I/II errors, $p$-values, $z$, $t$, $\chi^2$, $F$, regression inference. Know the meaning, not a software menu.

### This skill, specifically

CIs, hypothesis tests, Type I/II errors, $p$-values, $z$, $t$, $\chi^2$, $F$, regression inference.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

In simple linear regression $Y_i=\beta_0+\beta_1 x_i+\varepsilon_i$ with iid $N(0,\sigma^2)$ errors, $\hat\beta_1$ is normal, $\dfrac{\hat\beta_1-\beta_1}{\mathrm{se}(\hat\beta_1)}\sim t_{n-2}$, where $\mathrm{se}(\hat\beta_1)=\hat\sigma/\sqrt{\sum(x_i-\bar x)^2}$ and $\hat\sigma^2=\mathrm{SSE}/(n-2)$. Testing $H_0:\beta_1=0$ asks whether a linear $x$-effect is detectable.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** If $\hat\beta_1=2$, $\mathrm{se}=0.5$, $n=12$, observed $t$ for $H_0:\beta_1=0$.

**Solution.** $t=4$ on $10$ df.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** df for simple linear regression $t$-tests is

**Solution.** $n-2$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Using $n-1$ df, or interpreting ‘not rejecting $\beta_1=0$’ as proving $x$ is unrelated in every nonlinear sense.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** If all $x_i$ are equal, $\mathrm{se}(\hat\beta_1)$ is

**Solution.** undefined/infinite: no slope information.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** A $95\%$ CI for $\beta_1$ is

**Solution.** $\hat\beta_1\pm t_{n-2,0.025}\,\mathrm{se}(\hat\beta_1)$.

## 9. Lock it in

You own this skill when you can do Drill 1 and Drill 2 tomorrow, mixed among unrelated problems, in under five minutes each, with the traps named in Section 7 avoided on purpose.
