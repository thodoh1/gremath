# Lesson M-491 — Gram-Schmidt process

Part K. K. Linear Algebra · **Inner-product spaces** · High

Prerequisites: `K.1-K.7`.


This lesson isolates **Gram-Schmidt process** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Linear algebra is a large share of the algebra portion. Rank, kernels, eigenvalues, and determinants are exam staples.

## 1. Why this skill exists

If you cannot do **Gram-Schmidt process**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Inner-product spaces*

Inner products give geometry: orthogonality, norms, projections, Gram–Schmidt, least squares. Symmetric real matrices are orthogonally diagonalizable (spectral theorem). SVD is the rectangular cousin.

### This skill, specifically

Inner products give geometry: orthogonality, norms, projections, Gram–Schmidt, least squares.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

Gram–Schmidt: from a basis $\{x_1,\ldots,x_n\}$, set $v_1=x_1$ and $v_k=x_k-\sum_{j=1}^{k-1}\mathrm{proj}_{v_j}x_k$. Then $\{v_k\}$ is orthogonal and spans the same flags. Normalize $u_k=v_k/\|v_k\|$ for an ONB. The process fails if some $x_k$ already lies in the previous span (linear dependence).

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Apply GS to $x_1=(1,1,0)$, $x_2=(1,0,1)$.

**Solution.** $v_1=(1,1,0)$. $\mathrm{proj}_{v_1}x_2=\frac12(1,1,0)$, so $v_2=\bigl(\frac12,-\frac12,1\bigr)$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** If $x_2$ is already orthogonal to $x_1$, then $v_2$ equals

**Solution.** $x_2$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Projecting onto the $u_j$ that have not yet been constructed, or subtracting $\mathrm{proj}_{x_j}$ instead of $\mathrm{proj}_{v_j}$.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** GS on $(1,0)$, $(1,1)$ in $\mathbb{R}^2$.

**Solution.** $v_1=(1,0)$, $v_2=(0,1)$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** The span of the first $k$ $v$'s equals

**Solution.** the span of the first $k$ $x$'s.
