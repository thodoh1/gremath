# Lesson M-737 — Relations

Part Q. Q. Logic, Sets & Proof · **Set theory** · High

Prerequisites: `Q.1-Q.3`.


This lesson isolates **Relations** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Logic and proof are how other items are worded. Counting and analysis both depend on quantifiers.

## 1. Why this skill exists

If you cannot do **Relations**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

A relation on $A$ is a subset $R\subset A\times A$; one writes $aRb$ for $(a,b)\in R$. Reflexive: $\forall a,\, aRa$. Symmetric: $aRb\Rightarrow bRa$. Transitive: $aRb$ and $bRc\Rightarrow aRc$. Antisymmetric: $aRb$ and $bRa\Rightarrow a=b$. $<$ on $\mathbb{R}$ is transitive, not reflexive.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Classify $<$ and $\le$ on $\mathbb{R}$ by the four properties.

**Solution.** $<$ is transitive, irreflexive, not symmetric. $\le$ is reflexive, antisymmetric, transitive (a partial order), not symmetric.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** The empty relation on a nonempty set is reflexive?

**Solution.** No: $aRa$ fails.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Checking transitivity only on a chain of three distinct elements and missing $aRa$ loops.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Is ``divides'' on $\mathbb{N}$ symmetric?

**Solution.** No: $2\mid 4$ but $4\nmid 2$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Equality on any set is

**Solution.** an equivalence relation (and a partial order).
