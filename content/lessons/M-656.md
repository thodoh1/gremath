# Lesson M-656 — Intermediate Value Theorem proof idea

Part O. O. Real Analysis · **Continuity** · High

Prerequisites: `E.2-O.2`.


This lesson isolates **Intermediate Value Theorem proof idea** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Real analysis items are often ‘which statement is true?’ definition checks inside additional topics.

## 1. Why this skill exists

If you cannot do **Intermediate Value Theorem proof idea**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Continuity*

$f$ is continuous at $a$ when $\lim_{x\to a}f(x)=f(a)$. Types of discontinuity (removable, jump, infinite) are classified by one-sided limits. IVT and EVT are the two big existence theorems for continuous functions on closed intervals.

### This skill, specifically

$f$ is continuous at $a$ when $\lim_{x\to a}f(x)=f(a)$.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

Intermediate Value Theorem: if $f$ is continuous on $[a,b]$ and $k$ lies between $f(a)$ and $f(b)$, then some $c\in[a,b]$ has $f(c)=k$. Proof idea: nested bisection, always keeping $k$ between the endpoint values; completeness produces $c$, and continuity forces $f(c)=k$. Equivalently, the continuous image of an interval is an interval.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Show $x^3+x-1=0$ has a root in $[0,1]$.

**Solution.** $f(0)=-1<0<1=f(1)$, IVT.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Does IVT require differentiability?

**Solution.** No: continuity on a compact interval is enough.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Applying IVT to a discontinuous function ($1_{\mathbb{Q}}$ misses values) or on an open set where the function blows up.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Must a continuous $f:\mathbb{R}\to\mathbb{R}$ be surjective if it takes both signs?

**Solution.** No: $\arctan$ takes both signs but misses $|y|\ge\pi/2$.

Cover that solution, redo the drill on paper, then continue.
