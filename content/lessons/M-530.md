# Lesson M-530 — Legendre symbol

Part L. L. Number Theory · **Additional elementary number theory** · Medium

Prerequisites: `L.2-L.3`.


This lesson isolates **Legendre symbol** and trains it until it is automatic.

This is a Medium skill: it appears less often, but when it appears it is often a discriminator. Number theory is additional-topics / algebra: congruences, Euler, CRT.

## 1. Why this skill exists

If you cannot do **Legendre symbol**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

The Legendre symbol $\bigl(\frac{a}{p}\bigr)$ for odd prime $p$ is $0$ if $p\mid a$, $+1$ if $a$ is a nonzero quadratic residue mod $p$, and $-1$ if a nonresidue. Euler's criterion: $\bigl(\frac{a}{p}\bigr)\equiv a^{(p-1)/2}\pmod{p}$. Completely multiplicative in $a$: $\bigl(\frac{ab}{p}\bigr)=\bigl(\frac{a}{p}\bigr)\bigl(\frac{b}{p}\bigr)$. $\bigl(\frac{-1}{p}\bigr)=(-1)^{(p-1)/2}$, $\bigl(\frac{2}{p}\bigr)=(-1)^{(p^2-1)/8}$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

Write the hypotheses, apply the move, check the conclusion against the question asked.

## 5. Worked example

**Problem.** Compute $\bigl(\frac{3}{7}\bigr)$ by listing and by Euler.

**Solution.** Residues mod $7$ are $1,2,4$, so $3$ is a nonresidue: $-1$. Euler: $3^3=27\equiv 6\equiv -1\pmod{7}$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $\bigl(\frac{-1}{13}\bigr)$ equals

**Solution.** $1$ because $13\equiv 1\pmod{4}$. (For $p\equiv 3\pmod{4}$ it is $-1$.)

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Using $\bigl(\frac{a}{p}\bigr)=a\bmod p$, or applying Legendre at a composite ‘prime’.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** $\bigl(\frac{2}{7}\bigr)$.

**Solution.** $7\equiv -1\pmod{8}$, so $+1$ (the symbol is $-1$ iff $p\equiv\pm 3\pmod{8}$). Check: $3^2=9\equiv 2\pmod{7}$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** $\bigl(\frac{5}{11}\bigr)$ by Euler: $5^5\bmod 11$.

**Solution.** $5^2=3$, $5^4=9$, $5^5=45\equiv 1\pmod{11}$, so $+1$.
