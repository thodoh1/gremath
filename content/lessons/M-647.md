# Lesson M-647 — Ratio/root tests from analysis perspective

Part O. O. Real Analysis · **Series & convergence** · High

Prerequisites: `G.2-O.2`.


This lesson isolates **Ratio/root tests from analysis perspective** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Real analysis items are often ‘which statement is true?’ definition checks inside additional topics.

## 1. Why this skill exists

If you cannot do **Ratio/root tests from analysis perspective**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

Ratio test: $L=\lim |a_{n+1}/a_n|$ (if the limit exists). $L<1$ absolute convergence, $L>1$ (or $L=\infty$) divergence, $L=1$ inconclusive. Root test: $\rho=\limsup |a_n|^{1/n}$, same conclusions. Both are comparison with a geometric series.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Apply the ratio test to $\sum n!/n^n$.

**Solution.** $|a_{n+1}/a_n|=(n/(n+1))^n\to 1/e<1$, so the series converges absolutely.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Ratio test on $\sum 1/n$ and $\sum 1/n^2$ both give

**Solution.** $L=1$, inconclusive (one diverges, one converges).

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Declaring divergence when $L=1$.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Root test on $\sum (2/3)^n$.

**Solution.** $(2/3)\to 2/3<1$, converges.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Ratio test for $\sum n^n x^n$ at $x=1/2$.

**Solution.** $|a_{n+1}/a_n|\to\infty$ if $x\neq 0$? At $x=1/2$: $\frac{(n+1)^{n+1}}{2^{n+1}}\frac{2^n}{n^n}=(n+1)(1+1/n)^n/2\to\infty>1$, diverges.

## 9. Lock it in

You own this skill when you can do Drill 1 and Drill 2 tomorrow, mixed among unrelated problems, in under five minutes each, with the traps named in Section 7 avoided on purpose.
