# Lesson M-967 — Relative error

Part X. X. Numerical Analysis · **Numerical error** · Medium

This lesson isolates **Relative error** and trains it until it is automatic.

This is a Medium skill: it appears less often, but when it appears it is often a discriminator. Numerical methods are additional topics: Newton, error, quadrature recognition.

## 3. Precise statement

Relative error is $|x-\hat x|/|x|$ for $x\neq 0$; percentage error is $100$ times that. It is dimensionless and appropriate when scale varies. Machine epsilon is a relative-error scale for rounding. If $\hat x=0$ and $x\neq 0$, relative error is $1$. Approximating a tiny $x$ with a modest absolute error can be a huge relative error.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.
