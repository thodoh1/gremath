## 3. Precise statement

A problem is well-conditioned if small relative changes in the data produce small relative changes in the true solution; ill-conditioned if not. The condition number of a differentiable map $f$ at $x\neq 0$ is $\kappa\approx |xf'(x)/f(x)|$ (relative-to-relative). For a matrix, $\kappa(A)=\|A\|\|A^{-1}\|$ (or $\sigma_{\max}/\sigma_{\min}$). Conditioning is about the problem, not the algorithm.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 5. Worked example

**Problem.** Condition of $f(x)=\sqrt{x}$ at $x>0$: $\kappa=|x\cdot \frac12 x^{-1/2}/\sqrt{x}|=1/2$. Well-conditioned.

**Solution.** Relative output error $\approx \frac12$ relative input error.

Now cover the solution and redo it. If you cannot, you are still in Section 2.
