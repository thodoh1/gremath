# Lesson M-535 — Multiplicative arithmetic functions

Part L. L. Number Theory · **Additional elementary number theory** · Medium

Prerequisites: `L.2-L.3`.


This lesson isolates **Multiplicative arithmetic functions** and trains it until it is automatic.

This is a Medium skill: it appears less often, but when it appears it is often a discriminator. Number theory is additional-topics / algebra: congruences, Euler, CRT.

## 1. Why this skill exists

If you cannot do **Multiplicative arithmetic functions**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

An arithmetic function $f$ is multiplicative if $\gcd(m,n)=1\Rightarrow f(mn)=f(m)f(n)$, and completely multiplicative if this holds for all $m,n$. Multiplicative functions are determined by their values at prime powers. $d,\sigma,\phi,\mu$ are multiplicative; $d$ and $\phi$ are not completely multiplicative. Dirichlet convolution preserves multiplicativity.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Check $\sigma(12)=\sigma(4)\sigma(3)$ and compare $\sigma(16)$ vs $\sigma(4)^2$.

**Solution.** $\sigma(4)=1+2+4=7$, $\sigma(3)=4$, product $28=\sigma(12)$. Completely? $\sigma(16)=1+2+4+8+16=31$, $\sigma(4)^2=49\neq 31$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Is $\phi$ completely multiplicative?

**Solution.** No: $\phi(4)=2$, $\phi(2)^2=1$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Using $f(p^k)=f(p)^k$ for a merely multiplicative $f$ (that is the complete case).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** If $f$ is multiplicative and $n=p^a q^b$, then $f(n)=$

**Solution.** $f(p^a)f(q^b)$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Is $\mu$ completely multiplicative?

**Solution.** No: $\mu(4)=0$, $\mu(2)\mu(2)=1$.
