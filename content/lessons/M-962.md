# Lesson M-962 — Residue theorem

Part W. W. Complex Analysis · **Residue methods** · Medium

Prerequisites: `W.3`.


This lesson isolates **Residue theorem** and trains it until it is automatic.

This is a Medium skill: it appears less often, but when it appears it is often a discriminator. Complex analysis is additional topics: Cauchy–Riemann, residues at a basic level.

## 1. Why this skill exists

If you cannot do **Residue theorem**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Residue methods*

Simple-pole residue $p/q'$ or $\lim(z-z_0)f$, residue theorem $2\pi i\sum\mathrm{Res}$, argument principle, winding numbers, real integrals via semicircles as awareness.

### This skill, specifically

Simple-pole residue $p/q'$ or $\lim(z-z_0)f$, residue theorem $2\pi i\sum\mathrm{Res}$, argument principle, winding numbers, real integrals via semicircles as awareness.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

Residue theorem: if $\gamma$ is a simple closed positively oriented contour and $f$ is holomorphic on and inside $\gamma$ except for finitely many isolated singularities $a_k$ inside, then $\int_\gamma f=2\pi i\sum_k \mathrm{Res}(f,a_k)$. Orientation reversal changes the sign. Exterior residues including $\infty$ sum to $0$ on the Riemann sphere for a rational function (sum of all residues including $\infty$ is $0$).

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** $\int_{|z|=2}\dfrac{1}{z(z-1)}\,dz$.

**Solution.** Poles at $0,1$ both inside: Res at $0$ is $-1$, at $1$ is $1$, sum $0$, integral $0$. Alternatively partial fractions $1/(z-1)-1/z$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 7. Traps that cost points

- Forgetting $2\pi i$, omitting a singularity inside, or using clockwise orientation without a minus sign.
- Skip checking a candidate in the original equation.
