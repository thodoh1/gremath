# Lesson M-560 — Index of subgroup

Part M. M. Group Theory · **Cosets & Lagrange** · High

Prerequisites: `M.1-M.2`.


This lesson isolates **Index of subgroup** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Group theory is the main abstract-algebra GRE diet: orders, Lagrange, homomorphisms.

## 1. Why this skill exists

If you cannot do **Index of subgroup**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Cosets & Lagrange*

Left/right cosets partition $G$. $|G|=|H|\,[G:H]$. Lagrange: $|H|$ divides $|G|$. Consequences: orders of elements divide $|G|$; groups of prime order are cyclic.

### This skill, specifically

Left/right cosets partition $G$.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

The index $[G:H]$ is the number of distinct left cosets of $H$ in $G$ (equal to the number of right cosets). If $G$ is finite, $[G:H]=|G|/|H|$. Index can be infinite: $[\mathbb{Z}:\{0\}]=\infty$, $[\mathbb{Z}:n\mathbb{Z}]=n$. Multiplicativity: $[G:K]=[G:H][H:K]$ when $K\le H\le G$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Compute $[S_3:A_3]$ and $[\mathbb{Z}:4\mathbb{Z}]$.

**Solution.** $|S_3|/|A_3|=6/3=2$. $[\mathbb{Z}:4\mathbb{Z}]=4$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Index of $SL_n(\mathbb{R})$ in $GL_n(\mathbb{R})$

**Solution.** Infinite: det takes all of $\mathbb{R}^\times$, so $[GL:SL]=|\mathbb{R}^\times|$. More cleanly the cosets are determined by det, infinitely many.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Writing $[G:H]=|H|/|G|$.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** $[A_4:V]$ for the Klein four $V\trianglelefteq A_4$.

**Solution.** $12/4=3$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** If $[G:H]=2$, then $H$ is

**Solution.** normal (left cosets $=$ right cosets: $H$ and its complement).
