# Lesson M-525 — Modular obstructions to integer solutions

Part L. L. Number Theory · **Diophantine equations** · High

Prerequisites: `L.1-L.2`.


This lesson isolates **Modular obstructions to integer solutions** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Number theory is additional-topics / algebra: congruences, Euler, CRT.

## 1. Why this skill exists

If you cannot do **Modular obstructions to integer solutions**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Diophantine equations*

$ax+by=c$ is solvable iff $\gcd(a,b)\mid c$. General integer solutions follow Bézout. Modular obstructions kill many equations instantly. Pythagorean triples and Pell are extra pattern libraries.

### This skill, specifically

$ax+by=c$ is solvable iff $\gcd(a,b)\mid c$.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

A modular obstruction shows an equation has no integer (or rational) solutions: if a congruence implied by the equation is impossible, so is the original. Typical: squares are $0,1\bmod 4$ never $3$; cubes $0,\pm 1\bmod 9$; $ax+by=c$ fails if $\gcd(a,b)\nmid c$. Working modulo a well-chosen $n$ is the GRE default obstruction.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Show $x^2+y^2=4k+3$ has no integer solutions.

**Solution.** Squares $\bmod 4$ are $0$ or $1$, so sums are $0,1,2$, never $3\bmod 4$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $15x+25y=7$ over $\mathbb{Z}$

**Solution.** Impossible: $\gcd=5\nmid 7$. Equivalently $0\equiv 2\pmod{5}$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Checking only modulo $2$ when the obstruction lives at $4$ or $8$ (e.g. $x^2\equiv 7\pmod{8}$ is already impossible).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Can $n^2\equiv 2\pmod{4}$?

**Solution.** No.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Is $x^2-5y^2=2$ possible mod $5$?

**Solution.** $x^2\equiv 2\pmod{5}$. Squares mod $5$ are $0,1,4$. No.

## 9. Lock it in

You own this skill when you can do Drill 1 and Drill 2 tomorrow, mixed among unrelated problems, in under five minutes each, with the traps named in Section 7 avoided on purpose.
