# Lesson M-750 — Cantor diagonal argument

Part Q. Q. Logic, Sets & Proof · **Functions & cardinality** · High

Prerequisites: `Q.4`.


This lesson isolates **Cantor diagonal argument** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Logic and proof are how other items are worded. Counting and analysis both depend on quantifiers.

## 1. Why this skill exists

If you cannot do **Cantor diagonal argument**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Functions & cardinality*

Injection, surjection, bijection, composition, inverses. Countable vs uncountable, Cantor diagonal, $|\mathbb{N}|=|\mathbb{Z}|=|\mathbb{Q}|<|\mathbb{R}|$, axiom of choice as awareness.

### This skill, specifically

Injection, surjection, bijection, composition, inverses.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

Cantor's diagonal argument: if $(x_n)$ were a list of all reals in $(0,1)$, write decimal expansions $x_n=0.d_{n1}d_{n2}\ldots$ and define $e_n\neq d_{nn}$ with $e_n\in\{1,2\}$ (avoiding $0$ and $9$ to dodge dual representations). Then $0.e_1 e_2\ldots$ differs from each $x_n$ in the $n$th place, contradiction. Hence $(0,1)$ is uncountable.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Given a purported list $0.5000\ldots$, $0.3333\ldots$, $0.1415\ldots$, construct a diagonal number using digits $1$ and $2$.

**Solution.** First digits $5,3,1$. Choose $e_1=1$ ($\neq 5$), $e_2=1$ ($\neq 3$), $e_3=2$ ($\neq 1$), and continue; the result is not on the list.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Why avoid digit $9$ in the diagonal construction?

**Solution.** So the new number is not a terminating expansion equal to another listing of some $x_n$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Diagonalizing only finitely many places, or using binary expansions without care about $0.0111\ldots=0.1000\ldots$.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** The same idea shows $\{0,1\}^{\mathbb{N}}$ is uncountable: the diagonal sequence

**Solution.** flips the $n$th bit of the $n$th sequence.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Does the argument show $|\mathbb{R}|>|\mathbb{N}|$ or merely that one listing fails?

**Solution.** It shows every listing fails, hence no bijection with $\mathbb{N}$.
