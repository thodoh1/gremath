# Lesson M-366 — Scalar line integrals

Part I. I. Vector Calculus · **Line integrals** · High

Prerequisites: `I.1`.


This lesson isolates **Scalar line integrals** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Vector calculus (Green/Stokes/divergence) appears less often than single-variable calculus but is a high-leverage discriminator.

## 1. Why this skill exists

If you cannot do **Scalar line integrals**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Line integrals*

Scalar line integrals weight by arc length. Vector line integrals measure work $\int_C\mathbf{F}\cdot d\mathbf{r}$. Conservative fields are gradients: path independence, $\mathbf{F}=\nabla f$, curl zero (on simply connected domains).

### This skill, specifically

Scalar line integrals weight by arc length.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

The scalar line integral $\int_C f\,ds=\int_a^b f(\mathbf{r}(t))\,|\mathbf{r}'(t)|\,dt$ is independent of orientation (speed enters through $|\mathbf{r}'|$). It computes mass if $f$ is density, or arc-length when $f\equiv 1$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** $f=x+y$ along $\mathbf{r}(t)=(t,2t)$, $t\in[0,1]$. Compute $\int_C f\,ds$.

**Solution.** $|\mathbf{r}'|=\sqrt{5}$, $f=3t$, so $\int_0^1 3t\sqrt{5}\,dt=3\sqrt{5}/2$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Arc length of $\mathbf{r}(t)=(3t,4t)$ from $t=0$ to $1$ is

**Solution.** $5$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Using $\mathbf{r}'$ instead of $|\mathbf{r}'|$, which accidentally inserts an orientation and is the vector-line-integral measure.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** $\int_C 1\,ds$ on the unit circle.

**Solution.** $2\pi$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Does reversing $C$ change $\int f\,ds$?

**Solution.** No.
