# Lesson M-248 — Differentials and error approximation

Part E. E. Calculus I — Limits & Differentiation · **Applications of derivatives** · Critical

Prerequisites: `E.3-E.4`.


This lesson isolates **Differentials and error approximation** and trains it until it is automatic.

This is a Critical skill: it is used constantly, and a hole here leaks points all over the paper. This is the core of the calculus half of the exam. Limits, derivatives, and applications are everywhere.

## 1. Why this skill exists

If you cannot do **Differentials and error approximation**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

The differential $df=f'(x)\,dx$ estimates $\Delta f$. Relative error $|\Delta f/f|$; percentage $100$ times that. For products, logarithmic differentials add relative errors.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** If $x=2$ with possible error $0.01$, estimate error in $x^3$.

**Solution.** $d(x^3)=3x^2 dx=12\cdot 0.01=0.12$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Relative error in $A=\pi r^2$ is

**Solution.** $2\,|dr/r|$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Adding absolute errors of factors instead of relative errors for a product.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** $f=1/x$ at $x=10$, $dx=0.1$, $df$.

**Solution.** $-0.1/100=-0.001$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** If all sides of a cube are $2\%$ high, volume is about

**Solution.** $6\%$ high (three relative errors).
