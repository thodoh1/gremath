# Lesson M-445 — Parametric vector form

Part K. K. Linear Algebra · **Systems & row reduction** · Critical

Prerequisites: `K.2`.


This lesson isolates **Parametric vector form** and trains it until it is automatic.

This is a Critical skill: it is used constantly, and a hole here leaks points all over the paper. Linear algebra is a large share of the algebra portion. Rank, kernels, eigenvalues, and determinants are exam staples.

## 1. Why this skill exists

If you cannot do **Parametric vector form**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

Parametric vector form writes the general solution as $\mathbf{x}=\mathbf{p}+t_1\mathbf{v}_1+\cdots+t_k\mathbf{v}_k$, where $\mathbf{p}$ is a particular solution and $\{\mathbf{v}_j\}$ is a basis of $\mathrm{Nul}\,A$ (free-variable columns with a $-1$ in the free slot after moving to the other side). The solution set is an affine subspace.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

Write the hypotheses, apply the move, check the conclusion against the question asked.

## 5. Worked example

**Problem.** $x+2y-z=4$, one free pair. Parametric vector form (take $y,z$ free).

**Solution.** $x=4-2s+t$, so $\mathbf{x}=\begin{pmatrix}4\\0\\0\end{pmatrix}+s\begin{pmatrix}-2\\1\\0\end{pmatrix}+t\begin{pmatrix}1\\0\\1\end{pmatrix}$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** If there are $2$ free variables, the solution set is a

**Solution.** plane (2-flat) if consistent, possibly not through the origin.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Using the pivot columns as the null-space spanning set (those are column-space generators).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** $\mathbf{x}=\begin{pmatrix}1\\2\end{pmatrix}+t\begin{pmatrix}3\\-1\end{pmatrix}$ describes

**Solution.** the line through $(1,2)$ in direction $(3,-1)$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** When $\mathbf{p}=\mathbf{0}$, the parametric form describes

**Solution.** a subspace (homogeneous).
