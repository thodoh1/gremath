# Lesson M-626 — Least-upper-bound property

Part O. O. Real Analysis · **Real-number foundations** · High

Prerequisites: `A.1`.


This lesson isolates **Least-upper-bound property** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Real analysis items are often ‘which statement is true?’ definition checks inside additional topics.

## 1. Why this skill exists

If you cannot do **Least-upper-bound property**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Real-number foundations*

$\mathbb{R}$ is a complete ordered field: every nonempty set bounded above has a least upper bound. Suprema, infima, Archimedean property, density of $\mathbb{Q}$ and of irrationals, nested intervals.

### This skill, specifically

$\mathbb{R}$ is a complete ordered field: every nonempty set bounded above has a least upper bound.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

Least-upper-bound property: every nonempty $S\subset\mathbb{R}$ that is bounded above has a least upper bound $\sup S\in\mathbb{R}$. This is the completeness axiom for $\mathbb{R}$; it fails in $\mathbb{Q}$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Let $S=\{q\in\mathbb{Q}:q^2<2\}$. Is $S$ bounded above in $\mathbb{Q}$? Does it have a least upper bound in $\mathbb{Q}$?

**Solution.** Yes (e.g. $2$). No: any rational upper bound $r$ can be decreased while remaining an upper bound, because $\sqrt{2}\notin\mathbb{Q}$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** Does $(0,1)$ have a least upper bound in $\mathbb{R}$?

**Solution.** Yes: $1$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Claiming the LUB must lie in $S$ (that is a maximum, not a supremum).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Does $\mathbb{N}$ have a least upper bound in $\mathbb{R}$?

**Solution.** No: $\mathbb{N}$ is not bounded above.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** If $S=\{x\in\mathbb{R}:x^2<2\}$, what is $\sup S$?

**Solution.** $\sqrt{2}$, which is not in $S$.

## 9. Lock it in

You own this skill when you can do Drill 1 and Drill 2 tomorrow, mixed among unrelated problems, in under five minutes each, with the traps named in Section 7 avoided on purpose.
