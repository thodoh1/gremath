# Lesson M-607 — Module definition

Part N. N. Rings, Modules & Fields · **Modules** · Medium

Prerequisites: `N.1`.


This lesson isolates **Module definition** and trains it until it is automatic.

This is a Medium skill: it appears less often, but when it appears it is often a discriminator. Rings and fields appear as recognition and finite examples, especially $\mathbb{Z}/n\mathbb{Z}$ and $F[x]$.

## 1. Why this skill exists

If you cannot do **Module definition**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Modules*

Modules are vector spaces over rings. Submodules, quotients, homomorphisms, generators, free modules. When the ring is a field, you recover linear algebra.

### This skill, specifically

Modules are vector spaces over rings.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

A (left) module over a unital ring $R$ is an abelian group $M$ with a scalar map $R\times M\to M$ satisfying $r(m+n)=rm+rn$, $(r+s)m=rm+sm$, $(rs)m=r(sm)$, $1m=m$. $\mathbb{Z}$-modules are abelian groups. $R$-modules include $R^n$, ideals of $R$, and $R/I$. If $R$ is a field, modules are vector spaces.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Why is every abelian group uniquely a $\mathbb{Z}$-module?

**Solution.** $n\cdot g=g+\cdots+g$ ($n$ times), and $(-n)\cdot g=-(n\cdot g)$. Uniqueness of this structure: the axioms force it. So there is only one $\mathbb{Z}$-module structure on a given abelian group.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** An ideal $I\subseteq R$ is an $R$-module via

**Solution.** the ring multiplication.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Forgetting $1m=m$ (unital module axiom), which allows pathological scalar actions.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Is $\mathbb{Z}/n\mathbb{Z}$ a $\mathbb{Z}$-module?

**Solution.** Yes: the quotient abelian group.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** $R$ as a module over itself is

**Solution.** the regular module; submodules are (left) ideals.
