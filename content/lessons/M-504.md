# Lesson M-504 — Bézout identity

Part L. L. Number Theory · **Divisibility & primes** · High

Prerequisites: `A.1-A.3`.


This lesson isolates **Bézout identity** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Number theory is additional-topics / algebra: congruences, Euler, CRT.

## 1. Why this skill exists

If you cannot do **Bézout identity**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

Bézout: $\gcd(a,b)$ is an integer linear combination: there exist $x,y\in\mathbb{Z}$ with $ax+by=\gcd(a,b)$. The set of all combinations $ax+by$ is exactly $\gcd(a,b)\mathbb{Z}$. In particular $ax+by=1$ is solvable iff $a,b$ are coprime. Coefficients come from back-substituting the Euclidean algorithm.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Find $x,y$ with $56x+15y=1$.

**Solution.** $56=3\cdot 15+11$, $15=1\cdot 11+4$, $11=2\cdot 4+3$, $4=1\cdot 3+1$. Back-sub: $1=4-3=4-(11-2\cdot 4)=3\cdot 4-11=3(15-11)-11=3\cdot 15-4\cdot 11=3\cdot 15-4(56-3\cdot 15)=15\cdot 15-4\cdot 56$. So $x=-4$, $y=15$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $6x+9y=2$ has integer solutions?

**Solution.** No: $\gcd(6,9)=3\nmid 2$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Claiming Bézout coefficients are unique (they are not: add $b/d$ and subtract $a/d$).
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Express $\gcd(12,8)$ as $12x+8y$.

**Solution.** $4=12\cdot 1+8\cdot(-1)$, for instance.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Does $10x+15y=5$ have solutions?

**Solution.** Yes, $3\mid 5$; e.g. $x=2$, $y=-1$.
