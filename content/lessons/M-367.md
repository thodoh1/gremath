# Lesson M-367 — Vector line integrals

Part I. I. Vector Calculus · **Line integrals** · High

Prerequisites: `I.1`.


This lesson isolates **Vector line integrals** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Vector calculus (Green/Stokes/divergence) appears less often than single-variable calculus but is a high-leverage discriminator.

## 1. Why this skill exists

If you cannot do **Vector line integrals**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Line integrals*

Scalar line integrals weight by arc length. Vector line integrals measure work $\int_C\mathbf{F}\cdot d\mathbf{r}$. Conservative fields are gradients: path independence, $\mathbf{F}=\nabla f$, curl zero (on simply connected domains).

### This skill, specifically

Scalar line integrals weight by arc length.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

The vector line integral $\int_C\mathbf{F}\cdot d\mathbf{r}=\int_a^b \mathbf{F}(\mathbf{r}(t))\cdot\mathbf{r}'(t)\,dt$. Equivalently $\int_C P\,dx+Q\,dy+R\,dz$. Reversing $C$ changes the sign. It is not the same as $\int f\,ds$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** $\mathbf{F}=(y,x)$ along $y=x$ from $(0,0)$ to $(1,1)$. Compute $\int_C\mathbf{F}\cdot d\mathbf{r}$.

**Solution.** $\mathbf{r}(t)=(t,t)$, $\mathbf{F}\cdot\mathbf{r}'=(t,t)\cdot(1,1)=2t$, integral $1$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $\int_C x\,dx$ along $(0,0)$ to $(2,0)$ on the $x$-axis equals

**Solution.** $\int_0^2 t\,dt=2$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Inserting $|\mathbf{r}'|$ into a work integral, mixing $ds$ with $d\mathbf{r}$.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** $\mathbf{F}=(0,1)$ along $\mathbf{r}(t)=(t,t^2)$, $t:0\to 1$.

**Solution.** $\mathbf{F}\cdot\mathbf{r}'=2t$, integral $1$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** If $C$ is reversed, $\int_{-C}\mathbf{F}\cdot d\mathbf{r}$ equals

**Solution.** the negative of the original.
