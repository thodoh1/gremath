# Lesson M-362 — Velocity/acceleration vectors

Part I. I. Vector Calculus · **Vector fields** · High

Prerequisites: `H.2`.


This lesson isolates **Velocity/acceleration vectors** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. Vector calculus (Green/Stokes/divergence) appears less often than single-variable calculus but is a high-leverage discriminator.

## 1. Why this skill exists

If you cannot do **Velocity/acceleration vectors**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 2. From zero

### Landscape of *Vector fields*

A vector field assigns a vector to each point. Gradients are special fields. Velocity and acceleration are derivatives of vector-valued paths.

### This skill, specifically

A vector field assigns a vector to each point.

You are not learning the whole topic again. You are learning the exact move named in the title. Neighboring lessons exist; use them if a word here is still foreign, then come back.

## 3. Precise statement

If $\mathbf{r}(t)$ is position, velocity is $\mathbf{v}=\mathbf{r}'$ and acceleration is $\mathbf{a}=\mathbf{r}''$. Speed is $|\mathbf{v}|$, not $\mathbf{v}$ itself. Arc length from $a$ to $b$ is $\int_a^b|\mathbf{r}'(t)|\,dt$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** $\mathbf{r}(t)=(2\cos t,2\sin t,5t)$. Find $|\mathbf{v}|$ and $|\mathbf{a}|$.

**Solution.** $\mathbf{v}=(-2\sin t,2\cos t,5)$, $|\mathbf{v}|=\sqrt{4+25}=\sqrt{29}$. $\mathbf{a}=(-2\cos t,-2\sin t,0)$, $|\mathbf{a}|=2$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

**Solution.** $(2,6)$.

## 7. Traps that cost points

- Reporting $\mathbf{v}$ when the question asked for speed, or integrating $\mathbf{r}'$ instead of $|\mathbf{r}'|$ for length.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** Speed of $\mathbf{r}(t)=(\cos 4t,\sin 4t)$.

**Solution.** $4$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** Does constant speed imply $\mathbf{a}=\mathbf{0}$?

**Solution.** No: uniform circular motion has $\mathbf{a}\perp\mathbf{v}$, $\mathbf{a}\neq\mathbf{0}$.
