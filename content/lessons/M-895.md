# Lesson M-895 — F distribution

Part U. U. Mathematical Statistics · **Inference** · Medium

Prerequisites: `U.1-U.2`.


This lesson isolates **F distribution** and trains it until it is automatic.

This is a Medium skill: it appears less often, but when it appears it is often a discriminator. Statistics is lighter than probability but bias, MLE, and tests do appear.

## 1. Why this skill exists

If you cannot do **F distribution**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

$F_{\nu_1,\nu_2}=(U/\nu_1)/(V/\nu_2)$ where $U\sim\chi^2_{\nu_1}$, $V\sim\chi^2_{\nu_2}$ independent. Used to compare two normal variances: $s_1^2/s_2^2\sim F_{n_1-1,n_2-1}$ if $\sigma_1=\sigma_2$. Also the ANOVA ratio. $F$ is right-skewed; $1/F_{\nu_1,\nu_2}\sim F_{\nu_2,\nu_1}$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** If $s_1^2=10$, $s_2^2=5$ from independent normal samples with equal true variances, the $F$ statistic is

**Solution.** $2$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $E[F_{\nu_1,\nu_2}]$ for $\nu_2>2$ is

**Solution.** $\nu_2/(\nu_2-2)$, not $1$.

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Comparing variances with a $t$ table, or putting the smaller $s^2$ in the numerator and then using an upper-tail critical value without adjusting.
- Skip checking a candidate in the original equation.
