# Lesson M-397 — Stability

Part J. J. Differential Equations · **First-order ODEs** · High

Prerequisites: `F.1-E.3`.


This lesson isolates **Stability** and trains it until it is automatic.

This is a High skill: it is standard GRE material. You should be able to do it without warming up. ODEs appear as additional or calculus-adjacent items: separable, linear first order, characteristic equations.

## 1. Why this skill exists

If you cannot do **Stability**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

For $y'=f(y)$ with $f$ $C^1$, an equilibrium $y_*$ is asymptotically stable (attracting) if $f'(y_*)<0$, unstable if $f'(y_*)>0$. If $f'(y_*)=0$, the linear test fails (use the phase line). Stability is about nearby solutions as $x\to+\infty$.

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Classify $y=0$ and $y=1$ for $y'=y(1-y)$.

**Solution.** $f'(y)=1-2y$. $f'(0)=1>0$ unstable; $f'(1)=-1<0$ attracting.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 7. Traps that cost points

- Using $f''(y_*)$ instead of $f'(y_*)$, or swapping attracting/repelling.
- Skip checking a candidate in the original equation.

**Solution.** $y=2$ stable, $y=-2$ unstable.
