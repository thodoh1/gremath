# Lesson M-1023 — Solve proof-flavored multiple-choice problems

Part Y. Y. Mixed GRE Problem-Solving · **Hard-problem training** · Critical

Prerequisites: `A-Y`.


This lesson isolates **Solve proof-flavored multiple-choice problems** and trains it until it is automatic.

This is a Critical skill: it is used constantly, and a hole here leaks points all over the paper. This is not content weight; it is how every weighted item is actually scored under a clock.

## 1. Why this skill exists

If you cannot do **Solve proof-flavored multiple-choice problems**, every later item that secretly uses it becomes a two-minute panic. The GRE will not name the skill. It will drop you into a computation or a “which statement is true?” and wait.

## 3. Precise statement

Proof-flavored multiple choice asks which implication holds, which hypothesis is needed, or which statement is equivalent. Treat choices as propositions: test each on a $2\times 2$ matrix or a $C^0$ vs $C^1$ function. ‘Must be true’ means prove or cite a theorem; ‘could be true’ needs one example; ‘cannot be true’ needs an obstruction (parity, degree, compactness).

Copy that statement onto paper and replace each symbol with a tiny example. A definition you cannot instantiate is a definition you do not have.

## 4. How a working mathematician uses it

Write the hypotheses, apply the move, check the conclusion against the question asked.

On the exam, this should feel like a reflex: see the pattern, apply the move, check hypotheses, box the quantity asked for.

## 5. Worked example

**Problem.** Which must be true if $T:\mathbb{R}^2\to\mathbb{R}^2$ is linear and not invertible? (A) $T$ is not injective. (B) $T$ is diagonalizable. (C) $\det T=1$.

**Solution.** (A): for square linear maps, not invertible $\Leftrightarrow$ not injective $\Leftrightarrow$ not surjective. (B) fails for a shear; (C) fails because $\det=0$.

Now cover the solution and redo it. If you cannot, you are still in Section 2.

## 6. GRE-style problem

**Problem.** $f$ continuous on $[0,1]$. Which must be true? (A) $f$ differentiable. (B) $f$ bounded. (C) $f$ polynomial.

**Solution.** (B) by EVT. $|x|$ is a counterexample to (A) and (C).

Notice what was *not* done: no extra theory, no calculator, no essay. The governing idea, then the computation.

## 7. Traps that cost points

- Picking a sufficient condition that is not necessary and reading it as ‘must’.
- Skip checking a candidate in the original equation.

## 8. Drills

Work these closed-book. Then check.

**Drill 1.** ‘$A^2=I$ $\Rightarrow$ $A$ invertible’: must, could, or cannot?

**Solution.** Must: $A^{-1}=A$.

Cover that solution, redo the drill on paper, then continue.

**Drill 2.** ‘$f'=0$ a.e. $\Rightarrow$ $f$ constant’ for merely integrable $f'$: could fail (Cantor function is the famous continuous counterexample with $f'=0$ a.e.). On GRE, if $f$ is assumed $C^1$ on an interval, then

**Solution.** it must be constant.
